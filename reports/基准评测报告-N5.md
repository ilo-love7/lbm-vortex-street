**v1.2 深化（§7–§9）**：新增 MRT 碰撞算子（BGK 是其严格特例，单测机器精度等价）、9 点 Re 全曲线、涡量/速度探针双测法与 12 进程并行调度（32 项单测）。**三个核心结果**：① MRT「低 τ 稳定化」假说证伪——BGK 在 τ=0.524 已稳定，MRT 降噪随 Re/τ 非单调且把 Cd 系统抬高 +1.3~1.9%（动量交换法读到非平衡矩），默认仍用 BGK；② St 相对 Fey 的偏差从 +6.73%（Re=100）单调增到 +11.06%（Re=300），说明残余偏差含随 Re 增长的 2D 约束误差，而非仅固定 10% 阻塞，3D 校验优先级上调；③ 三站 uy/ω 探针与升力谱 St 完全一致（0.000%），互谱对流速度 U_c/U=0.59–0.75 给出涡间距 λ/D=3.16–3.83，信号二次谐波比 ~10⁻⁴（近纯正弦）。

**v1.3 深化（§10–§12）**：三实验收口 §9 的三个未做项，25/25 case 成功、12 进程墙钟 28.3 min、86 项单测。**三个核心结果**：① **阻塞比外推**——β=D/H 从 20%→5% 把 Re=100 的 St 偏差压 17.4pp、Cd 降 19.1%；β→0 外推口径敏感（线性 −4.06% / 二次 +2.35%），Re=250 残余仍有 +4.71%，说明随 Re 增长的 **2D 约束误差**消不掉，3D 校验仍是最高优先；② **四口径测力推翻 v1.2 的推测**——面积分（节点 Π 或严格链接守恒）都是离散守恒律的恒等变换，扣除累积项后逐位复现 MEM（最大差 <2e-12），根本判不了测力伪影；改用只读守恒矩的**严格两截面尾流亏损**后，Re=300 的 MRT 偏移在 WAKE 上是 **+1.24%**（MEM +1.18%），判定为**真实流场改变**而非读数伪影（同时量化两个反例：CV-node 围道分散 45–49%、经典 wake survey 低估 50%）；③ **2D LES 与入口扰动双负结果**——Smagorinsky 9/9 全稳但纯 BGK 在 τ₀=0.5075 已稳，LES 只用 4% 亚格子黏度就把 Re=800 的 Cd 抬高 10.9%、Cl 压低 8–19%，无任何稳定化收益；持续入口扰动即便加到 30% U，St 逐位不变、Cd 仅 +0.09%，独立诊断证明扰动被 v1.1 的目标态海绵完全吸收（x=26 之后 uy RMS 四档恒同），这既是慢波根治的机制，也限定了后续 VIV / 来流湍流度实验必须先改协议。

## §1 方法

### 1.1 D2Q9 + BGK

九速离散（Mocz 速度序），平衡分布

    f_eq,i = w_i ρ [1 + 3(c_i·u) + 4.5(c_i·u)² − 1.5u²]，

碰撞 F ← F − (1/τ)(F − F_eq)，迁移 np.roll 推进；粘度 ν = (τ−0.5)/3，雷诺数 Re = U D / ν。

### 1.2 边界条件（相对 Mocz 教学版的严谨化）

- **圆柱**：半程反弹（link-wise）f_ī(x_f,t+1) = f_i*(x_f,t)；
- **入口（西）**：Zou/He 速度入口 ux=U, uy=0，未知量 f2/f3/f4 解析解；
- **出口（东）**：一阶对流 ∂f/∂t + U_c ∂f/∂x = 0；
- **顶底**：自由滑移（镜面反射，cx 不变、cy 反向），近似无限域。

### 1.3 测力与 St

动量交换法（静壁）：F = 2 Σ_{圆柱链接} e_i f_i*，Cd = F_x/(½ρU²D)、Cl = F_y/(½ρU²D)。
St = f·D/U，f 取升力时程 Hann 窗 FFT 主频（抛物线插值细化）。文献经验式 St ≈ 0.2124 − 4.592/Re（Fey et al. 1998）。

### 1.4 实现与算力

numba JIT 内核与 numpy 路径逐位对照一致（max diff 8e-16），步耗时 54→9 ms（400×200）；生产网格 840×280 ≈ 26 ms/步，4 Re 并行 CPU，全程无数据集。

**稳定性教训**：τ = 3UD/Re+0.5 ≤ 0.53 时出入口+反弹边界组合泵能发散（纯周期 BGK 同 τ 稳定）；故 U=0.1、D=28 使 τ ≥ 0.542（Ma=0.17），详见工作记录 §3.6。

**要点**：
- **St 全部正误差 +7~15%**：粗网格（D=28）阶梯壁面使有效柱径偏大、涡街频率系统性偏高，是 LBM 粗解典型偏差；Re=50 误差最大（+14.6%）因其处周期性脱涡起振边缘（Re_cr≈47），升力幅仅 0.035，主频估计本身敏感。
- **Cl 幅值趋势正确**：0.035 → 0.394 → 0.599 → 0.868 随 Re 单调增长，与文献量级相当（偏高 ~15–25%，同源于阶梯壁面有效柱径）。
- **Cd 系统性偏高 +20~30%**：块均值稳定（见 2.2）但绝对值受阶梯壁面粗糙度、10% 阻塞（ny=10D）、Re=200 边界层仅 ~2 lu 三因素叠加推高。

### 2.2 力时程噪声与稳健口径（重要方法学发现）

瞬时 Cd 时程在 Re≥100 被宽带噪声污染，直接时均会被极值带偏。对记录时程做逐周期块统计（每 T≈D/(U·St) 一块）与前后三段对比：

| Re | 块均值 | 块间 std | 块 min–max | 前/中/后段 Cd | 负 Cd 占比（前/中/后） |
|---|---|---|---|---|---|
| 50 | 1.797 | 0.046 | 1.73–1.87 | 1.75 / 1.80 / 1.86 | 0% / 0% / 0% |
| 100 | 1.638 | 0.084 | 1.52–1.84 | 1.58 / 1.64 / 1.71 | 22% / 38% / 42% |
| 150 | 1.713 | 0.100 | 1.50–1.83 | 1.66 / 1.72 / 1.76 | 47% / 50% / 50% |
| 200 | 1.748 | 0.078 | 1.64–1.91 | 1.72 / 1.73 / 1.79 | 49% / 51% / 50% |

- **块均值极稳**（std 0.05–0.10，相对 3–6%）且随时间缓慢爬升（前→后 +3~5%，与边界层增厚/转捩前移一致）→ **Cd 块均值口径可信**，§2.1 采用此口径。
- Re=50 全程零负值、std 最小——τ=0.668 耗散强，干净。
- Re≥100 瞬时值约一半为负（无物理意义，稳态圆柱 Cd 恒正），是**零均值宽带噪声叠加在真值上**的表现，而非物理量本身失效；**Cl 与 St 不受污染**（升力主频、幅值均稳健，且 St 的两种测法——升力谱主频 vs 峰频——互差 <2%）。

**尖峰逐节点诊断**（Re=200，it≈22513，瞬时 Cd=6.06）：264 个圆柱链接的单节点动量贡献全部在 ±1.78 内（上游面 dir=3 约 +1.78/节点、下游面 min −1.65、垂直链接 CX=0 贡献恒 0），**无单点异常**；净 Cd=6 是「上游 +1.78×N 与下游 −1.65×N」大数抵消后 ~0.3% 残差的失衡。力时间线呈慢漂而非高频毛刺：it=8000 Cd=1.64 → 16000 Cd=3.29 → 22513 Cd=6.06 → 32000 Cd=0.80（双向漂移）。

**机制定位**（三组对照探针）：
1. 纯周期 x + 圆柱（无出入口），τ=0.542：12000 步稳定（|u|max≈0.135 不增长，Cd 有界 0.86–1.08）→ **核心 BGK + 半程反弹无罪**；
2. 只出入口（无圆柱）2 万步干净 → 出入口单独无罪；
3. 出入口 + 圆柱反弹组合 + 长时间 → 慢波累积（τ≤0.53 时甚至指数泵能发散，见 §1.4）。

结论：**Zou/He 入口 + 对流出口与反弹壁面的组合会在低 τ（≲0.55）向场内注入慢变压力波**；动量交换力是 ±1.7 量级大数的小残差（~1%），对慢波极敏感，故瞬时 Cd 先于 St/Cl 被污染。此为**边界处理 + 测力方法的组合局限**，非实现 bug。

## §3 结论与展望

### 3.1 结论

1. **求解器正确性**：从零实现的 D2Q9+BGK + 半程反弹 + Zou/He 入口 + 对流出口求解器通过 6 项单测（格子恒等式、feq 矩、无 nan、入口速度 BC、对称力、合成信号 St），numba/numpy 双路径逐位一致；Re=50–200 全部稳定收敛并产生物理卡门涡街（见涡量图与 GIF）。
2. **St 验证通过**：4 组 Re 相对误差 +7~15%，全部落在粗网格 LBM 预期偏差带内，且随 Re 误差收敛（Re=100–200 稳定在 +7~9%）。
3. **Cd/Cl 给出可信趋势但绝对值偏高 ~20%**：Cl 幅增长曲线正确；Cd 块均值口径稳定（块间 std ≤0.1），系统偏差来自阶梯壁面 + 阻塞 + 边界层欠分辨，属分辨率问题而非方法错误。
4. **方法学贡献（如实标注的局限）**：首次在本项目中标定「低 τ 边界泵能红线」（τ≤0.53 发散，τ≥0.542 稳定）；诊断出高 Re 长时力测量的慢波污染机制并给出可用口径（逐周期块均值 + Cl 相干幅）；瞬时力时程在 Re≥100 不可直接使用，已在 §2.2 全量披露（负值占比、块统计、逐节点抓拍、对照探针）。

### 3.2 v1.1 展望（提案深化方向）

1. **Bouzidi 次网格反弹**（代码已备 `src/lbm/bouzidi.py`，未接入）：消除阶梯壁面有效柱径误差，预期 Cd/St 偏差减半；需解决固体清零与 q<0.5 子网格镜像的存储冲突。

# v1.1 深化轮：Bouzidi 次网格反弹 + 海绵层（2026-11-09/10）

> 目标：打掉 v1.0 两大局限——阶梯壁面 Cd/St 偏差（+20~30%/+7~15%）与高 Re 力慢波污染。
> 手段：Bouzidi 解析壁距反弹（几何二阶）+ 东西海绵层（吸收边界反射慢波）+ 网格收敛验证。

## §4 v1.1 方法升级

### 4.1 Bouzidi 次网格反弹（公式定案）

对每条流体→固体链接按解析壁距 q∈(0,1]（|x_f+q e_i−C|=R 小根）线性插值
（Bouzidi 2000 / Lallemand-Luo 2003 式(12)(14) 两点极限；i 指向固体）：

    q < 1/2:  f_ī(x_f,t+1) = 2q·f_i*(x_f) + (1−2q)·f_i*(x_f−e_i)
    q ≥ 1/2:  f_ī(x_f,t+1) = (1/(2q))·f_i*(x_f) + ((2q−1)/(2q))·f_ī*(x_f)

两式均只读流体节点碰撞后值，不依赖固体节点（v1.0 备用实现曾误用 f_i*(x_s)——公式考古后纠正，
详见工作记录 §6.1）；q=0.5 退化半程反弹。静壁动量交换力同步改为
F = Σ_links e_i [f_i*(x_f) + f_ī_new(x_f)]（半程时恒等于旧式 2Σe_i f_i*，单测锁死）。

### 4.2 海绵层（慢波吸收）

东西两端各 32 lu 向目标态 feq(ρ0,U,0) 以 smoothstep 剖面弛豫（σ_max=0.08）：
慢波（密度波）出域前被吸收，不再经 Zou/He 入口/对流出口反射回场内污染力测量。
注意必须向**目标态**弛豫而非局部 feq——密度波就在局部 feq 里，局部弛豫压不掉。

### 4.3 稳定性红线外推

Bouzidi 削掉阶梯几何噪声源 + 海绵吸收残余慢波后，Re=300（τ=0.528，v1.0 红线 τ≤0.53 以下）
1 万步稳定（|u|max 有界、涡脱正常）——**泵能红线从 τ≈0.53 压到 0.528 以下**。

## §7 v1.2 方法升级

### 7.1 MRT 碰撞算子（可注入，BGK 是其特例）

按 d'Humières / Lallemand–Luo (2002) 的 D2Q9 矩基构造 `mrt.py`：

    m = M·f，  m_post = m + S·(m_eq − m)，  f* = M⁻¹·m_post
    S = diag(0, s_e, s_ε, 0, s_q, 0, s_q, s_ν, s_ν)，  s_ν = 1/τ

- 守恒矩（ρ, jx, jy）松弛率置 0；两个剪切矩 pxx/pxy 用 s_ν 保证 ν=(τ−0.5)/3 不变；
- **「magic」参数化**：s_e = s_ε = 1.1、s_q = 1.2（常用低噪声取值）；另备 `bulk`（全 1.0）与
  `bgk`（全 s_ν）。当 S 全取 s_ν 时 MRT 严格退化为 BGK——单测以机器精度锁死该等价性；
- 矩基按本包速度列序置换（LL 原始序 → `kernels.CX/CY` 序由 `_PERM` 显式给出）；平衡态矩
  `m_eq = [ρ, −2ρ+3|j|²/ρ, ρ−3|j|²/ρ, jx, −jx, jy, −jy, (jx²−jy²)/ρ, jx jy/ρ]`；
- **双路径一致性**：numba 内核用显式 9×9 双层循环（njit 内避免高维 dot），numpy 回退路径用
  `mrt_collide` 向量化；`CylinderCase` 新增 `collision`/`mrt_preset` 两个字段，BGK 路径零开销。

**待检验假说**：MRT 通过抑制非流体动力学（ghost）模态，应降低力时程噪声并可能把低 τ 稳定
边界再往下推（v1.1 已把红线由 0.53 推到 0.528 以下）。E10 用 Re=100/300/350
（τ=0.584/0.528/0.524）× {BGK, MRT} 六组同协议对照，判据为 4 块 Cd std、前后半漂移、
发散与否，而不是只看 Cd 均值。

### 7.3 涡量·探针双测法与互谱对流速度（E12）

`spectrum.py` 提供四个纯函数，统一沿用 `postprocess.strouhal` 的 Hann 窗 + 抛物线插值主频口径：

- `probe_st`：任意探针时程（uy、ω）的 St，频带 (0.02, 0.5)；
- `dual_st`：升力 St 与探针 St 的相对差，把 v1.1 的「双测法」从两种力谱扩展到流场探针；
- `convection_delay`：上下游探针互谱在基频处取相位差 → 最小正时滞 → U_c = Δx/Δt；
- `harmonic_ratio`：二次谐波/基波幅值比，量化涡脱落非正弦度。

Re=100/200 各跑 15T 瞬态 + 25T 记录，在中心线 x/D = 1.5/3/5 三站逐节点记录 uy 与
中心差分涡量 ω = ½(uy,x+1 − uy,x−1) − ½(ux,y+1 − ux,y−1)，同步记录升力。

### 7.4 工程改进：并行调度与断点缓存

`ok=False/error` 字段而不拖垮整批，汇总层 `collect` 只收成功项并在日志显式 WARN。设有
`--workers N` 与 `--force` 两个开关；8 项单测覆盖包级导出、任务表、缓存往返、失败容忍与合并口径。

### 10.1 E13 阻塞比 β→0 外推：分离「阻塞修正」与「2D 约束误差」

§8.2 发现 St 相对 Fey 经验式的偏差从 +6.73%（Re=100）单调增到 +11.06%（Re=300），
因此「+10% 阻塞」不足以解释全部残差。E13 固定 `D=20 / U=0.1 / nx=560 / cx_c=120`，
**只改域高** ny∈{100,140,200,300,400} ⇒ β=D/H∈{20%,14.3%,10%,6.7%,5%}
（Re=100 五档；Re=250 三档 100/200/400）。同一 τ、同一网格分辨率、同一边界协议，
唯一变量是壁面距离。对 St(β) / Cd(β) 做线性最小二乘外推到 β=0（无限域），
二次外推仅作 ≥4 点时的稳健性对照（3 点时 polyfit(2) 是精确插值，外推病态）：
**外推截距与文献 St 的残余差，就是加大计算域消不掉的部分**，即 2D 约束误差的
定量下界。协议 6T 瞬态 + 10T 记录，整周期平均见 `v13.period_average`。

### 10.2 E14 四口径测力：为什么「面积分」不能当独立判据

§9 原本期待「应力张量面积分」能判定 MRT 把 Cd 抬高 +1.3~1.9% 是物理还是
动量交换法（MEM）对非平衡矩的读数伪影。v1.3 实测后该期待被**修正**，最终
形成四个口径（`src/lbm/stress.py`、`src/lbm/wake.py`）：

1. **MEM**：`F=Σe_i[f_i*+f_ī,new]`，读圆柱反弹链接上的碰撞后分布。
2. **CV-node（朴素节点口径，方法学反例）**：在围道节点上对**碰撞前**分布
   二阶矩 `Π_αβ=Σ_i c_iα c_iβ f_i` 做 `−∮Π·n ds`。它看似不依赖 τ/矩基，
   但 LBM 离散动量守恒律的通量其实是**碰撞后**分布 `f*` 的二阶矩，
   二者相差 `Π^neq/τ` —— 恰是粘性应力量级。近场剪切强 → 系统性高估，
   且**违反围道无关性**（详见 §11.2）。
3. **CV-link（严格离散守恒，实现校验口径）**：直接从
   `f_i(x+c_i,t+1)=f_i*(x,t)` 与碰撞的动量守恒 `Σc_i f_i*=Σc_i f_i=ρu` 出发，
   对控制体 V 写
   `P_V(t+1)−P_V(t) = Σ_入 c_i f_i* − Σ_出 c_i f_i* + F_ext→fluid`；
   因 `f_i*(src,t) ≡ f_i(dst,t+1)`，故

       F_fluid→body(t) = Σ_i c_i [Σ_入 f_i(dst) − Σ_出 f_i(dst)] − [P_V(t+1)−P_V(t)]

   只读 `f` 与几何，不需要 τ / feq / 反弹链接 / 碰撞算子。实现上把跨 V 边界的
   链接**预计算**成 `(dst, dir, sign)` 表（`LinkFlux`），每步一次 fancy index。
4. **WAKE（唯一独立主判据）**：只读守恒矩 ρ / ρu，BGK 与 MRT 对守恒矩的
   弛豫率都恒为 0。取参考截面 `x_ref = sponge_width+2`（**西侧海绵之后、
   圆柱之前**的干净均匀流），下游站位 x/D∈{3,6,10}，写稳态两截面守恒

       F_D = Σ_{x_ref}(ρu_x² + p − σ'_xx) − Σ_x(ρu_x² + p − σ'_xx),  p=ρc_s²

   **不做质量守恒化简、不假设 p∞=ρ₀c_s²**。经典 wake survey
   `D=∫ρu(U−u)dy+∫(p∞−p)dy` 用 `∫ρU²dy=U∫ρu dy` 把上游通量化成 ρ₀U²H；
   本项目入口带目标态海绵（体积力源），x=1 截面已被弛豫，两个假设同时失效，
   经典口径实测**低估 53%**（§11.2），保留为反例对照。黏性法向应力在
   远场实测 <1e-4，`include_viscous` 可作稳健性开关。上下自由滑移壁跳过
   y=0 / y=ny−1 两行以避镜面反射密度伪影（已如实标注）。

**关键判据逻辑**：CV-link 扣除逐步累积项后是守恒律的**恒等式**，因此在
BGK 与 MRT 下都会逐位复现 MEM —— 它没有判别力，只用于验证实现正确性。
真正能定真伪的是 WAKE：若 MRT 偏移只是壁面读数伪影，只读守恒矩的远场
观测应不变；若 MRT 真改了平均流场，WAKE 应同步改变。

### 10.3 E15 Smagorinsky LES 与持续入口扰动

`src/lbm/les.py` 实现标准隐式 Smagorinsky：由非平衡矩范数
`Q=√(2Π^neq_αβ Π^neq_αβ)` 解二次方程
`τ_tot = ½[τ₀ + √(τ₀² + 18 C_s² Q/ρ)]`（`Q` 已含格子 Δx=1），
`ν_t/ν₀ = (τ_tot−τ₀)/(τ₀−0.5)`；`C_s=0` 精确退化为 BGK（单测逐位验证）。
LES 只改局部 τ，**不碰守恒矩**，因此与 MRT 互斥（构造时显式拒绝）。
因 LES 额外增黏，`CylinderCase` 的稳定性下限从经验 0.51 放宽到 `τ₀>0.5001`。

入口扰动用零均值横向速度
`u_y(y,t)=εU·[sin(2πm y/H + 2πt/T_f) 的组合]`，强迫周期取
`T_f=2.37·T_nat`（与固有脱落周期**非共振**，避免把 St 直接钉在驱动频率上）。
起振时间用滑动窗 RMS 首次达到饱和 RMS 90% 的时刻（`v13.onset_time`）。
判据：2D LES 是否真能稳定高 Re（而非只加数值耗散），以及持续来流扰动
是否改变统计吸引子与起振时间。

### 10.5 方法学校验（预研，小域 / 短协议，与 §11 生产跑口径分开）

在启动 25 case 生产批之前，用 360×120 / D=12 小域与 1T+2T 短协议做了三组
**能证伪**的校验，结论全部由单测锁死（`tests/test_v13_link_flux.py`）：

1. **CV-node 不是守恒通量、违反围道无关性**。840×280 大域诊断的三个围道
   h=18/22/28 给 Cd **2.2539 / 1.7824 / 1.3753**，而同期 MEM 只有 **1.2942**；
   加上 `−d/dt∫ρu` 累积修正后仍是 2.2542 / 1.7834 / 1.3777 —— 排除
   「只是非定常相位残差」。根因是 `Π=Σcc f`（碰撞前）与严格通量
   `Σcc f*`（碰撞后）相差 `Π^neq/τ`，近场剪切越强偏差越大。
2. **CV-link 是严格离散守恒恒等式，因此不独立**。小域 h=10/14/20 的原始
   链接法给 1.5389 / 1.5022 / 1.4534；扣除逐步累积项后**三个围道逐位完全
   一致（最大差 0.0）且逐位等于 MEM 1.570425**。在 840×280 短协议上，
   BGK / MRT 的 `link≡MEM` 逐步最大差分别为 **6.7e-13 / 1.5e-12**，
   即恒等式对 MRT 同样成立 —— **面积分必然跟随 MEM，判不了测力伪影**。
   同一短协议下 CV-node 的围道相对分散为 **48.4%**，链接口径为 0。
3. **经典 wake survey 低估 53%，且不是非定常项造成**。小域三站位
   x/D=3/6/10 给 Cd **0.6109 / 0.6089 / 0.6064**（MEM 1.3379）；加逐步
   累积修正后 0.6075 / 0.6064 / 0.6071，几乎不变。被积函数分解显示
   `momentum` 分项从 −0.0074 走到 −0.0952（**为负**），即 10% 阻塞下
   下游 `Σρu² > UΣρu`，质量守恒化简与 `p∞` 假设同时失效；西侧入口海绵
   又是体积力源。改用「西海绵之后两 clean 截面的 `(ρu²+p)` 直接相减」后，
   x/D=3/6/10/15 给 **1.3959 / 1.3880 / 1.3751 / 1.3664**，与 MEM 1.3558
   只差 +3.0%→+0.8% 且**随站位单调收敛**；黏性法向应力贡献 <1e-4。
   另在 840×280 短协议上，经典口径 / 严格口径 ≈ **0.44**，量级一致。

这三组校验直接改写了 §9 的展望条目：「应力张量面积分双口径互证」这个
提法本身不成立，最终实验改为**四口径 + 一个经典反例**，并把独立判据
交给只读守恒矩的 WAKE。

### 11.1 E13：β→0 外推把「阻塞修正」与「2D 约束误差」分离

3. **加大计算域消不掉的部分仍在，且随 Re 增长**：Re=250 线性外推残余

   §8.2 的 +6.73%→+11.06% 单调增同向：**2D 约束误差是随 Re 增长的
   独立误差源，不是固定阻塞底噪**。**3D 校验仍是最高优先未做项**。
4. Cd 的 β→0 外推给 Re=100 **1.259** / Re=250 **1.325**；2D 文献
   Cd≈1.35，线性口径偏低约 6.8%。Cd 的文献对照本身受 2D/3D 差异影响，
   此处只作趋势参考，不作为精度结论。

### 11.2 E14：MRT 的 Cd 偏移是**真实物理改变**，不是测力伪影

**表 C / 表 D / 表 G**。原域 840×280、BGK/MRT × Re=100/300，

|---|---|---:|---:|---:|---:|---:|

| 100 | MRT | 1.4393 | 0.9860 | 1.4393 | 1.4447 | 0.1762 |
| 300 | BGK | 1.4701 | 0.8857 | 1.4701 | 1.4772 | 0.2186 |
| 300 | MRT | 1.4875 | 0.9117 | 1.4875 | 1.4955 | 0.2182 |

1. **独立主判据给出明确判定**：Re=300 的 MRT−BGK 偏移，MEM 是
   **+1.18%**，只读守恒矩的 WAKE 是 **+1.24%**（比值 1.05，远超表 D
   「真实物理改变」阈值 0.7）。也就是说 **MRT 确实让远场尾流动量亏损
   变大了 1.24%，不只是壁面链接读数变了**。这推翻了 v1.2 §8.1 第 3 条

   稳定化 + 读数伪影」，它真实改变了二维平均流场。**默认仍用 BGK**
   的结论不变，但理由应改写为「MRT 在无稳定化收益的同时改变了定量

2. **偏移随 Re / τ 放大**：Re=100（τ=0.584）两算子几乎逐位一致

   在生产协议下高度一致，说明两截面口径已消除经典 wake survey 的

4. **两个方法学反例被量化**：CV-node 三个围道给 1.242/0.951/0.763
   （Re=100 BGK），围道相对分散 **45.2–48.7%**，且绝对值只有 MEM 的

   约 50%。二者都**不能**用来做定量 Cd 或判据，保留在表 G 供复核。

2. **LES 在 2D 是负收益**：Cd 本就因 10% 阻塞 / 2D 约束偏高，LES 把它

3. `C_s=0` 精确退化为 BGK（单测逐位验证），故 Cs=0 列可作同批次对照，

St 四档**逐位相同 0.2118**；Cd 1.4697→1.4710（+0.09%）、Cl 峰幅

（1.07e-4 → 5.98e-3），但西侧目标态海绵之后的 x=26 截面四档恒为

吸收，根本到不了圆柱。这同时解释了 v1.1 为何能根治慢波污染（入口 /
出口反射被同一层吸收），也给出一个**结构性边界**：本仓库协议下做不了
来流湍流度、VIV 入口激励这类实验，必须先改海绵（例如只在出口加海绵，
或把扰动注入点移到海绵之后）。初版 ε≤6% 的四档曾「逐位完全相同」，
是档位太窄造成的假负结果，扩大到 30% 后才看到 <0.6% 的微弱响应。

## §12 v1.3 结论与展望收口

1. **阻塞修正可定量分离，但消不掉 2D 约束误差**：β 从 20%→5% 把
   Re=100 的 St 偏差压 17.4pp；β→0 外推口径敏感（线性 −4.06% /
   二次 +2.35%），Re=250 的残余 +4.71% 仍随 Re 增长。**3D 校验仍是
   最高优先未做项**，且优先级高于继续加大二维计算域。
2. **§9 的「应力张量面积分双口径互证」提法被证伪并升级**：面积分
   （无论节点 Π 还是严格链接守恒）都是离散动量守恒律的恒等变换，
   扣除累积项后逐位复现 MEM，判不了测力伪影。改用只读守恒矩的
   **严格两截面尾流亏损**后，才判定出 v1.2 的 MRT Cd 偏移在 Re=300
   是 **+1.24% 的真实流场改变**（MEM +1.18%），而非读数伪影。
   默认 BGK 不变，但理由要改写。
3. **额外耗散 / 矩调整在 2D 均无正收益**：MRT（v1.2）与 Smagorinsky
   LES（v1.3）都稳定化证伪，且都系统性抬高 Cd；LES 在 Re=800 用
   4% 的亚格子黏度把 Cd 抬高 10.9%。入口扰动被目标态海绵完全屏蔽，

   来流湍流度实验必须先改协议的约束。
