## §1 方法

### 1.1 D2Q9 + BGK

九速离散（Mocz 速度序），平衡分布

    f_eq,i = w_i ρ [1 + 3(c_i·u) + 4.5(c_i·u)² − 1.5u²]，

碰撞 F ← F − (1/τ)(F − F_eq)，迁移 np.roll 推进；粘度 ν = (τ−0.5)/3，雷诺数 Re = U D / ν。

### 1.2 边界条件（相对 Mocz 教学版的严谨化）

- **圆柱**：半程反弹（link-wise）f_ī(x_f,t+1) = f_i*(x_f,t)；
- **入口（西）**：Zou/He 速度入口 ux=U, uy=0，未知量 f2/f3/f4 解析解；
- **出口（东）**：一阶对流 ∂f/∂t + U_c ∂f/∂x = 0；
- **顶底**：自由滑移（镜面反射，cx 不变、cy 反向），近似无限域。

### 1.3 测力与 St

动量交换法（静壁）：F = 2 Σ_{圆柱链接} e_i f_i*，Cd = F_x/(½ρU²D)、Cl = F_y/(½ρU²D)。
St = f·D/U，f 取升力时程 Hann 窗 FFT 主频（抛物线插值细化）。文献经验式 St ≈ 0.2124 − 4.592/Re（Fey et al. 1998）。

### 1.4 实现与算力

numba JIT 内核与 numpy 路径逐位对照一致（max diff 8e-16），步耗时 54→9 ms（400×200）；生产网格 840×280 ≈ 26 ms/步，4 Re 并行 CPU，全程无数据集。

**稳定性教训**：τ = 3UD/Re+0.5 ≤ 0.53 时出入口+反弹边界组合泵能发散（纯周期 BGK 同 τ 稳定）；故 U=0.1、D=28 使 τ ≥ 0.542（Ma=0.17），详见工作记录 §3.6。

**要点**：
- **St 全部正误差 +7~15%**：粗网格（D=28）阶梯壁面使有效柱径偏大、涡街频率系统性偏高，是 LBM 粗解典型偏差；Re=50 误差最大（+14.6%）因其处周期性脱涡起振边缘（Re_cr≈47），升力幅仅 0.035，主频估计本身敏感。
- **Cl 幅值趋势正确**：0.035 → 0.394 → 0.599 → 0.868 随 Re 单调增长，与文献量级相当（偏高 ~15–25%，同源于阶梯壁面有效柱径）。
- **Cd 系统性偏高 +20~30%**：块均值稳定（见 2.2）但绝对值受阶梯壁面粗糙度、10% 阻塞（ny=10D）、Re=200 边界层仅 ~2 lu 三因素叠加推高。

### 2.2 力时程噪声与稳健口径（重要方法学发现）

瞬时 Cd 时程在 Re≥100 被宽带噪声污染，直接时均会被极值带偏。对记录时程做逐周期块统计（每 T≈D/(U·St) 一块）与前后三段对比：

| Re | 块均值 | 块间 std | 块 min–max | 前/中/后段 Cd | 负 Cd 占比（前/中/后） |
|---|---|---|---|---|---|
| 50 | 1.797 | 0.046 | 1.73–1.87 | 1.75 / 1.80 / 1.86 | 0% / 0% / 0% |
| 100 | 1.638 | 0.084 | 1.52–1.84 | 1.58 / 1.64 / 1.71 | 22% / 38% / 42% |
| 150 | 1.713 | 0.100 | 1.50–1.83 | 1.66 / 1.72 / 1.76 | 47% / 50% / 50% |
| 200 | 1.748 | 0.078 | 1.64–1.91 | 1.72 / 1.73 / 1.79 | 49% / 51% / 50% |

- **块均值极稳**（std 0.05–0.10，相对 3–6%）且随时间缓慢爬升（前→后 +3~5%，与边界层增厚/转捩前移一致）→ **Cd 块均值口径可信**，§2.1 采用此口径。
- Re=50 全程零负值、std 最小——τ=0.668 耗散强，干净。
- Re≥100 瞬时值约一半为负（无物理意义，稳态圆柱 Cd 恒正），是**零均值宽带噪声叠加在真值上**的表现，而非物理量本身失效；**Cl 与 St 不受污染**（升力主频、幅值均稳健，且 St 的两种测法——升力谱主频 vs 峰频——互差 <2%）。

**尖峰逐节点诊断**（Re=200，it≈22513，瞬时 Cd=6.06）：264 个圆柱链接的单节点动量贡献全部在 ±1.78 内（上游面 dir=3 约 +1.78/节点、下游面 min −1.65、垂直链接 CX=0 贡献恒 0），**无单点异常**；净 Cd=6 是「上游 +1.78×N 与下游 −1.65×N」大数抵消后 ~0.3% 残差的失衡。力时间线呈慢漂而非高频毛刺：it=8000 Cd=1.64 → 16000 Cd=3.29 → 22513 Cd=6.06 → 32000 Cd=0.80（双向漂移）。

**机制定位**（三组对照探针）：
1. 纯周期 x + 圆柱（无出入口），τ=0.542：12000 步稳定（|u|max≈0.135 不增长，Cd 有界 0.86–1.08）→ **核心 BGK + 半程反弹无罪**；
2. 只出入口（无圆柱）2 万步干净 → 出入口单独无罪；
3. 出入口 + 圆柱反弹组合 + 长时间 → 慢波累积（τ≤0.53 时甚至指数泵能发散，见 §1.4）。

结论：**Zou/He 入口 + 对流出口与反弹壁面的组合会在低 τ（≲0.55）向场内注入慢变压力波**；动量交换力是 ±1.7 量级大数的小残差（~1%），对慢波极敏感，故瞬时 Cd 先于 St/Cl 被污染。此为**边界处理 + 测力方法的组合局限**，非实现 bug。

## §3 结论与展望

### 3.1 结论

1. **求解器正确性**：从零实现的 D2Q9+BGK + 半程反弹 + Zou/He 入口 + 对流出口求解器通过 6 项单测（格子恒等式、feq 矩、无 nan、入口速度 BC、对称力、合成信号 St），numba/numpy 双路径逐位一致；Re=50–200 全部稳定收敛并产生物理卡门涡街（见涡量图与 GIF）。
2. **St 验证通过**：4 组 Re 相对误差 +7~15%，全部落在粗网格 LBM 预期偏差带内，且随 Re 误差收敛（Re=100–200 稳定在 +7~9%）。
3. **Cd/Cl 给出可信趋势但绝对值偏高 ~20%**：Cl 幅增长曲线正确；Cd 块均值口径稳定（块间 std ≤0.1），系统偏差来自阶梯壁面 + 阻塞 + 边界层欠分辨，属分辨率问题而非方法错误。
4. **方法学贡献（如实标注的局限）**：首次在本项目中标定「低 τ 边界泵能红线」（τ≤0.53 发散，τ≥0.542 稳定）；诊断出高 Re 长时力测量的慢波污染机制并给出可用口径（逐周期块均值 + Cl 相干幅）；瞬时力时程在 Re≥100 不可直接使用，已在 §2.2 全量披露（负值占比、块统计、逐节点抓拍、对照探针）。

### 3.2 v1.1 展望（提案深化方向）

# v1.1 深化轮：Bouzidi 次网格反弹 + 海绵层（2026-11-09/10）

> 目标：打掉 v1.0 两大局限——阶梯壁面 Cd/St 偏差（+20~30%/+7~15%）与高 Re 力慢波污染。
> 手段：Bouzidi 解析壁距反弹（几何二阶）+ 东西海绵层（吸收边界反射慢波）+ 网格收敛验证。

## §4 v1.1 方法升级

### 4.1 Bouzidi 次网格反弹（公式定案）

对每条流体→固体链接按解析壁距 q∈(0,1]（|x_f+q e_i−C|=R 小根）线性插值
（Bouzidi 2000 / Lallemand-Luo 2003 式(12)(14) 两点极限；i 指向固体）：

    q < 1/2:  f_ī(x_f,t+1) = 2q·f_i*(x_f) + (1−2q)·f_i*(x_f−e_i)
    q ≥ 1/2:  f_ī(x_f,t+1) = (1/(2q))·f_i*(x_f) + ((2q−1)/(2q))·f_ī*(x_f)

两式均只读流体节点碰撞后值，不依赖固体节点（v1.0 备用实现曾误用 f_i*(x_s)——公式考古后纠正，
详见工作记录 §6.1）；q=0.5 退化半程反弹。静壁动量交换力同步改为
F = Σ_links e_i [f_i*(x_f) + f_ī_new(x_f)]（半程时恒等于旧式 2Σe_i f_i*，单测锁死）。

### 4.2 海绵层（慢波吸收）

东西两端各 32 lu 向目标态 feq(ρ0,U,0) 以 smoothstep 剖面弛豫（σ_max=0.08）：
慢波（密度波）出域前被吸收，不再经 Zou/He 入口/对流出口反射回场内污染力测量。
注意必须向**目标态**弛豫而非局部 feq——密度波就在局部 feq 里，局部弛豫压不掉。

## §7 v1.2 方法升级

### 7.1 MRT 碰撞算子（可注入，BGK 是其特例）

按 d'Humières / Lallemand–Luo (2002) 的 D2Q9 矩基构造 `mrt.py`：

    m = M·f，  m_post = m + S·(m_eq − m)，  f* = M⁻¹·m_post
    S = diag(0, s_e, s_ε, 0, s_q, 0, s_q, s_ν, s_ν)，  s_ν = 1/τ

- 守恒矩（ρ, jx, jy）松弛率置 0；两个剪切矩 pxx/pxy 用 s_ν 保证 ν=(τ−0.5)/3 不变；
- **「magic」参数化**：s_e = s_ε = 1.1、s_q = 1.2（常用低噪声取值）；另备 `bulk`（全 1.0）与
  `bgk`（全 s_ν）。当 S 全取 s_ν 时 MRT 严格退化为 BGK——单测以机器精度锁死该等价性；
- 矩基按本包速度列序置换（LL 原始序 → `kernels.CX/CY` 序由 `_PERM` 显式给出）；平衡态矩
  `m_eq = [ρ, −2ρ+3|j|²/ρ, ρ−3|j|²/ρ, jx, −jx, jy, −jy, (jx²−jy²)/ρ, jx jy/ρ]`；
- **双路径一致性**：numba 内核用显式 9×9 双层循环（njit 内避免高维 dot），numpy 回退路径用
  `mrt_collide` 向量化；`CylinderCase` 新增 `collision`/`mrt_preset` 两个字段，BGK 路径零开销。

**待检验假说**：MRT 通过抑制非流体动力学（ghost）模态，应降低力时程噪声并可能把低 τ 稳定
边界再往下推（v1.1 已把红线由 0.53 推到 0.528 以下）。E10 用 Re=100/300/350
（τ=0.584/0.528/0.524）× {BGK, MRT} 六组同协议对照，判据为 4 块 Cd std、前后半漂移、
发散与否，而不是只看 Cd 均值。

### 7.3 涡量·探针双测法与互谱对流速度（E12）

`spectrum.py` 提供四个纯函数，统一沿用 `postprocess.strouhal` 的 Hann 窗 + 抛物线插值主频口径：

- `probe_st`：任意探针时程（uy、ω）的 St，频带 (0.02, 0.5)；
- `dual_st`：升力 St 与探针 St 的相对差，把 v1.1 的「双测法」从两种力谱扩展到流场探针；
- `convection_delay`：上下游探针互谱在基频处取相位差 → 最小正时滞 → U_c = Δx/Δt；
- `harmonic_ratio`：二次谐波/基波幅值比，量化涡脱落非正弦度。

Re=100/200 各跑 15T 瞬态 + 25T 记录，在中心线 x/D = 1.5/3/5 三站逐节点记录 uy 与
中心差分涡量 ω = ½(uy,x+1 − uy,x−1) − ½(ux,y+1 − ux,y−1)，同步记录升力。

### 7.4 工程改进：并行调度与断点缓存

12 个 case 在 24 核机器上用进程池并行（默认 12 workers），每个 case 独立完成即把结果写
`results/v12_cache/<key>.json`；重跑自动跳过已完成项，任一 worker 异常（含低 τ 发散）转成
`ok=False/error` 字段而不拖垮整批，汇总层 `collect` 只收成功项并在日志显式 WARN。设有
`--workers N` 与 `--force` 两个开关；8 项单测覆盖包级导出、任务表、缓存往返、失败容忍与合并口径。
串行需约 3–4 小时的批实验，墙钟压缩到单个最长 case 的量级。
（实测 12 进程并行时单 case 慢约 2.5 倍——内存带宽饱和——但总吞吐仍提升 4–5 倍，

### 10.1 E13 阻塞比 β→0 外推：分离「阻塞修正」与「2D 约束误差」

§8.2 发现 St 相对 Fey 经验式的偏差从 +6.73%（Re=100）单调增到 +11.06%（Re=300），
因此「+10% 阻塞」不足以解释全部残差。E13 固定 `D=20 / U=0.1 / nx=560 / cx_c=120`，
**只改域高** ny∈{100,140,200,300,400} ⇒ β=D/H∈{20%,14.3%,10%,6.7%,5%}
（Re=100 五档；Re=250 三档 100/200/400）。同一 τ、同一网格分辨率、同一边界协议，
唯一变量是壁面距离。对 St(β) / Cd(β) 做线性最小二乘外推到 β=0（无限域），
二次外推仅作 ≥4 点时的稳健性对照（3 点时 polyfit(2) 是精确插值，外推病态）：
**外推截距与文献 St 的残余差，就是加大计算域消不掉的部分**，即 2D 约束误差的
定量下界。协议 6T 瞬态 + 10T 记录，整周期平均见 `v13.period_average`。

### 10.2 E14 四口径测力：为什么「面积分」不能当独立判据

§9 原本期待「应力张量面积分」能判定 MRT 把 Cd 抬高 +1.3~1.9% 是物理还是
动量交换法（MEM）对非平衡矩的读数伪影。v1.3 实测后该期待被**修正**，最终
形成四个口径（`src/lbm/stress.py`、`src/lbm/wake.py`）：

1. **MEM**：`F=Σe_i[f_i*+f_ī,new]`，读圆柱反弹链接上的碰撞后分布。
2. **CV-node（朴素节点口径，方法学反例）**：在围道节点上对**碰撞前**分布
   二阶矩 `Π_αβ=Σ_i c_iα c_iβ f_i` 做 `−∮Π·n ds`。它看似不依赖 τ/矩基，
   但 LBM 离散动量守恒律的通量其实是**碰撞后**分布 `f*` 的二阶矩，
   二者相差 `Π^neq/τ` —— 恰是粘性应力量级。近场剪切强 → 系统性高估，
   且**违反围道无关性**（详见 §11.2）。
3. **CV-link（严格离散守恒，实现校验口径）**：直接从
   `f_i(x+c_i,t+1)=f_i*(x,t)` 与碰撞的动量守恒 `Σc_i f_i*=Σc_i f_i=ρu` 出发，
   对控制体 V 写
   `P_V(t+1)−P_V(t) = Σ_入 c_i f_i* − Σ_出 c_i f_i* + F_ext→fluid`；
   因 `f_i*(src,t) ≡ f_i(dst,t+1)`，故

       F_fluid→body(t) = Σ_i c_i [Σ_入 f_i(dst) − Σ_出 f_i(dst)] − [P_V(t+1)−P_V(t)]

   只读 `f` 与几何，不需要 τ / feq / 反弹链接 / 碰撞算子。实现上把跨 V 边界的
   链接**预计算**成 `(dst, dir, sign)` 表（`LinkFlux`），每步一次 fancy index。
4. **WAKE（唯一独立主判据）**：只读守恒矩 ρ / ρu，BGK 与 MRT 对守恒矩的
   弛豫率都恒为 0。取参考截面 `x_ref = sponge_width+2`（**西侧海绵之后、
   圆柱之前**的干净均匀流），下游站位 x/D∈{3,6,10}，写稳态两截面守恒

       F_D = Σ_{x_ref}(ρu_x² + p − σ'_xx) − Σ_x(ρu_x² + p − σ'_xx),  p=ρc_s²

   **不做质量守恒化简、不假设 p∞=ρ₀c_s²**。经典 wake survey
   `D=∫ρu(U−u)dy+∫(p∞−p)dy` 用 `∫ρU²dy=U∫ρu dy` 把上游通量化成 ρ₀U²H；
   本项目入口带目标态海绵（体积力源），x=1 截面已被弛豫，两个假设同时失效，
   经典口径实测**低估 53%**（§11.2），保留为反例对照。黏性法向应力在
   远场实测 <1e-4，`include_viscous` 可作稳健性开关。上下自由滑移壁跳过
   y=0 / y=ny−1 两行以避镜面反射密度伪影（已如实标注）。

**关键判据逻辑**：CV-link 扣除逐步累积项后是守恒律的**恒等式**，因此在
BGK 与 MRT 下都会逐位复现 MEM —— 它没有判别力，只用于验证实现正确性。
真正能定真伪的是 WAKE：若 MRT 偏移只是壁面读数伪影，只读守恒矩的远场
观测应不变；若 MRT 真改了平均流场，WAKE 应同步改变。

### 10.3 E15 Smagorinsky LES 与持续入口扰动

`src/lbm/les.py` 实现标准隐式 Smagorinsky：由非平衡矩范数
`Q=√(2Π^neq_αβ Π^neq_αβ)` 解二次方程
`τ_tot = ½[τ₀ + √(τ₀² + 18 C_s² Q/ρ)]`（`Q` 已含格子 Δx=1），
`ν_t/ν₀ = (τ_tot−τ₀)/(τ₀−0.5)`；`C_s=0` 精确退化为 BGK（单测逐位验证）。
LES 只改局部 τ，**不碰守恒矩**，因此与 MRT 互斥（构造时显式拒绝）。
因 LES 额外增黏，`CylinderCase` 的稳定性下限从经验 0.51 放宽到 `τ₀>0.5001`。

入口扰动用零均值横向速度
`u_y(y,t)=εU·[sin(2πm y/H + 2πt/T_f) 的组合]`，强迫周期取
`T_f=2.37·T_nat`（与固有脱落周期**非共振**，避免把 St 直接钉在驱动频率上）。
起振时间用滑动窗 RMS 首次达到饱和 RMS 90% 的时刻（`v13.onset_time`）。
判据：2D LES 是否真能稳定高 Re（而非只加数值耗散），以及持续来流扰动
是否改变统计吸引子与起振时间。

### 10.5 方法学校验（预研，小域 / 短协议，与 §11 生产跑口径分开）

在启动 25 case 生产批之前，用 360×120 / D=12 小域与 1T+2T 短协议做了三组
**能证伪**的校验，结论全部由单测锁死（`tests/test_v13_link_flux.py`）：

1. **CV-node 不是守恒通量、违反围道无关性**。840×280 大域诊断的三个围道
   h=18/22/28 给 Cd **2.2539 / 1.7824 / 1.3753**，而同期 MEM 只有 **1.2942**；
   加上 `−d/dt∫ρu` 累积修正后仍是 2.2542 / 1.7834 / 1.3777 —— 排除
   「只是非定常相位残差」。根因是 `Π=Σcc f`（碰撞前）与严格通量
   `Σcc f*`（碰撞后）相差 `Π^neq/τ`，近场剪切越强偏差越大。
2. **CV-link 是严格离散守恒恒等式，因此不独立**。小域 h=10/14/20 的原始
   链接法给 1.5389 / 1.5022 / 1.4534；扣除逐步累积项后**三个围道逐位完全
   一致（最大差 0.0）且逐位等于 MEM 1.570425**。在 840×280 短协议上，
   BGK / MRT 的 `link≡MEM` 逐步最大差分别为 **6.7e-13 / 1.5e-12**，
   即恒等式对 MRT 同样成立 —— **面积分必然跟随 MEM，判不了测力伪影**。
   同一短协议下 CV-node 的围道相对分散为 **48.4%**，链接口径为 0。
3. **经典 wake survey 低估 53%，且不是非定常项造成**。小域三站位
   x/D=3/6/10 给 Cd **0.6109 / 0.6089 / 0.6064**（MEM 1.3379）；加逐步
   累积修正后 0.6075 / 0.6064 / 0.6071，几乎不变。被积函数分解显示
   `momentum` 分项从 −0.0074 走到 −0.0952（**为负**），即 10% 阻塞下
   下游 `Σρu² > UΣρu`，质量守恒化简与 `p∞` 假设同时失效；西侧入口海绵
   又是体积力源。改用「西海绵之后两 clean 截面的 `(ρu²+p)` 直接相减」后，
   x/D=3/6/10/15 给 **1.3959 / 1.3880 / 1.3751 / 1.3664**，与 MEM 1.3558
   只差 +3.0%→+0.8% 且**随站位单调收敛**；黏性法向应力贡献 <1e-4。
   另在 840×280 短协议上，经典口径 / 严格口径 ≈ **0.44**，量级一致。

这三组校验直接改写了 §9 的展望条目：「应力张量面积分双口径互证」这个
提法本身不成立，最终实验改为**四口径 + 一个经典反例**，并把独立判据
交给只读守恒矩的 WAKE。

   推得更高（Re=800 到 1.663）；Cl 被抹平意味着涡街强度被人为削弱。
   亚格子黏度只占分子黏度 1–4% 就能改动 Cd 一成，说明**高 Re 二维涡街
   对数值耗散极敏感**，用 LES 做定量 Cd 需先有 3D 基准。
3. `C_s=0` 精确退化为 BGK（单测逐位验证），故 Cs=0 列可作同批次对照，
   排除「换实现带来的偏差」。

**持续入口扰动（ε = 0 / 5% / 15% / 30% U）**

St 四档**逐位相同 0.2118**；Cd 1.4697→1.4710（+0.09%）、Cl 峰幅
0.6735→0.6772（+0.55%）、起振 2.11T→2.09T（提前 0.02T）。也就是说
即使把来流横向扰动加到 30% U，**统计吸引子也没有改变**。

机制由独立的衰减诊断给出：入口 `u_y` 的 RMS 随 ε 线性涨 56×
（1.07e-4 → 5.98e-3），但西侧目标态海绵之后的 x=26 截面四档恒为
**1.46e-3**，圆柱前 2D 的 x=60 恒为 **4.83e-3** —— 扰动被海绵完全
吸收，根本到不了圆柱。这同时解释了 v1.1 为何能根治慢波污染（入口 /
出口反射被同一层吸收），也给出一个**结构性边界**：本仓库协议下做不了
来流湍流度、VIV 入口激励这类实验，必须先改海绵（例如只在出口加海绵，
或把扰动注入点移到海绵之后）。初版 ε≤6% 的四档曾「逐位完全相同」，
是档位太窄造成的假负结果，扩大到 30% 后才看到 <0.6% 的微弱响应。

## §13 v1.4 方法升级：三维（D3Q19）校验内核

§12 把「3D 校验」列为最高优先未做项，并注明其优先级高于继续加大二维计算域。
v1.4 的目标不是把二维代码"加一维"凑出一个三维算例，而是先建一个**能被解析解
钉死**的 D3Q19 求解器（`src/lbm/lattice3d.py` / `kernels3d.py` / `solver3d.py`），
再用它回答两个只有三维能回答的问题：① Re=100 的展向周期圆柱是否真的二维
（若真二维，v1.2/v1.3 的全部 2D 结论就不受维度怀疑）；② β→0 外推的残余在
三维下是否消失（若消失，残余就是 2D 约束误差；若不消失，另有来源）。

### 13.1 三个"看起来只是加一维"的致命差异

**（1）自由滑移壁必须用镜面映射表，不能用对向表。** y 壁的理想镜面把
`(c_x,c_y,c_z)` 映到 `(c_x,−c_y,c_z)`：切向分量守恒、法向分量反号。三维的
"对向"是 `(−c_x,−c_y,−c_z)`，对棱心方向（如 `(1,±1,0)`）二者完全不同 ——
用对向表会把切向动量一并带走。实测误用 `OPP3` 时，均匀流 `u_x` 在 400 步内
从 0.1 掉到 0.0075（吃掉 92%），且残差是系统性衰减而不是噪声。
因此单独生成 `SPEC_Y3`（`lattice3d._specular_y_table`）：**表内 19 个条目有
16 个与 `OPP3` 不同**；真正参与壁面交换的是 `c_y≠0` 的 10 个方向，其中
**8 个棱心方向与对向不同，2 个 y 面心 `(0,±1,0)` 恰好相同**（对向即镜面）。

**（2）三维 Zou/He 入口要按"已知/未知集合"重推。** 二维 +x 入口的未知集是
`c_x=−1` 的 3 个方向，三维是 `c_x=−1` 的 5 个（面心 1 + 棱心 4），且棱心的
未知量互不独立（沿 y、z 的切向动量约束耦合）。实现取一般形式：记未知集 K、
已知集 U=A∪K 的零法向通量和 A、K 内部和 A_K、两集合的 `c_x` 和 s_U/s_K，由
`Σ_U f = A + A_K`、`Σ_U c_x f = ρu_x` 得

    ρ = (A + A_K) / (1 − s_U + s_K)

未知向取 `f_i = feq_i(ρ,u) + [f_j − feq_j(ρ,u)]`（j 为镜面对向）。单测锁
`u_x=0.1±2e-3`、`ρ=1±5e-3`。

**（3）`prange` 下不能有任何跨节点共享的临时数组。** 首版把 `feq` 缓冲区提到
`prange` 循环外复用，编译通过、结果"看起来像流场"，但四项解析判据同时超差：
Poiseuille 幅值 −11%、剪切波反测黏度 10 倍、TG 衰减率偏差数倍、圆柱
`Cd=20.18`（大一个量级）。原因是多线程写同一块缓冲区造成数据竞争。改为
**每节点内联重算 feq**（多算 19 次多项式，换确定性）后全部回到机器精度内。
这条写进 `kernels3d.collide_sponge3d` 的模块注释，避免后人"优化"回去。

### 13.2 三重解析判据：各锁一个自由度

单靠一个解析解无法定位错误。三个判据的分工是：

| 判据 | 锁什么 | 配置 | 判据式 |
|---|---|---|---|
| 平面 Poiseuille | 稳态、半程反弹壁、Guo 体积力 | ny=9/17/33/65, τ=0.7, g=1e-6 | `u_max=gH²/(8ν)`，L2 二阶收敛 |
| 剪切波衰减 | 碰撞算子的黏性率 ∂/∂τ、`ν=(τ−1/2)/3` | n=16/24, τ=0.55/0.6/0.8/1.2 | `A=A₀e^{−νk²t}` 反测 ν |
| 3D Taylor-Green | 三维非线性项、压力-散度耦合、各向同性 | n=32/48, τ=0.55/0.8 | `dlnE/dt` at t=0 `=−6νk_l²` |

三个**口径陷阱**，每一个都会给出"看起来合理但是错"的数：

- **Poiseuille 的步数必须随 H² 缩放**。稳态建立的特征时间是
  `t_diff=H²/(π²ν)`。首轮统一 40000 步，H=63 只折合 6.6 个特征时间，残余瞬变
  `e^{−6.6}≈1.4e-3` 与二阶离散误差同量级 —— 结果 ny=65 的 L2 反而比 ny=33 大
  （1.65e-3 vs 1.50e-3），log 收敛阶算出 **−0.13**，看起来像"壁面处理降阶"。
  改为 `steps=8H²/ν`（≥4000）并回传末段 1000 步的幅值漂移 `drift` 作收敛证据后，
  收敛阶恢复 2.00。
- **剪切波拟合窗口必须按相对幅值，不能按绝对阈值**。首轮用 `amps>1e-16` 选点。
  τ=1.2 时 `νk²≈0.036/步`，840 步内幅值就从 1e-3 跌到 double 舍入噪声（~1e-19），
  末段"有效点"全是噪声，log 斜率被拉平，ν 低估 **25.3%**（n=24 同 τ 只有 0.56%，
  这正是"网格越细反而越准"的反常）。改为 `A/A₀∈[1e-3,0.6]` 后回到与低 τ 档同量级。
- **TG 的波数是格子波数**：模式 `sin(2πi/n)` 的 `k_l=2π/n`，离散 Laplacian 本征值
  `−(2π/n)²`，故斜率是 `−6ν(2π/n)²`。若按物理单位取 `|k|²=3`，会得到约 2π 倍的
  假偏差（n=32 时正好 6.3 倍）—— 已写成回归单测
  `test_taylor_green_needs_lattice_wavenumber`，锁死口径。

### 13.3 3D-2D 对照协议

固定 `nx=320`、`D=16`、`cx_c=80`、`U=0.1`、`Re=100`（τ=0.5333）、海绵宽 32、
展向周期 `nz=16`；**只改域高** `ny∈{80,160,320}` ⇒ β=20%/10%/5%。2D 用完全相同
的 `(nx,ny,D,cx_c,U,Re,海绵)` 跑**同一协议：16T 瞬态 + 10T 记录**
（`T=D/(U·St_lit)≈975` 步）。注意下游只有 15D，比 v1.1 网格收敛算例的 20D 短：
这会让绝对 Cd 偏高约 3%（§14.5），但不影响 3D-2D 对照——两边共享同一域长。
三维尾流观测按 20 步抽样，由 `Solver3D.sample_metrics()` **一次宏量**同时给出
三个站位与展向诊断 —— 旧实现每个记录步调 4 次 `macros3d`（每次约 0.3 s，三维
网格下更贵），会把 β=5% 档从半小时拖成数小时。展向另跑 β=20% 的 `nz∈{8,16,24}`
（§14.4：它只能证明"没有三维结构"，不能当收敛性证据）。

**瞬态长度不是可调参数，是判据。** 首轮沿用 v1.3 的 6T 瞬态，得到
β=20% 差 0.05%、β=5% 差 0.00%，但 β=10% 差 2.0%（3D St 0.1759 vs 2D 0.1795），
且 3D 的 St(β) 序列非单调 —— 看上去像"三维效应只在低阻塞显现"。查下来
**与维度无关**：把同一个 2D 求解器（`ny=160`）的瞬态从 6T 拉到 16T，

| T_TRANS | St | Cd | Cl_rms | wake Cd |
|---|---|---|---|---|
| 6T | 0.17950 | 1.4789 | 0.1966 | 1.4883 |
| 12T | 0.18107 | 1.5335 | 0.2535 | 1.5402 |
| 16T | 0.18109 | 1.5348 | 0.2550 | 1.5414 |
| 20T | 0.18109 | 1.5350 | 0.2576 | 1.5414 |
| 24T | 0.18109 | 1.5347 | 0.2556 | 1.5415 |

16T 起三项指标全部持平到 1e-4。**6T 低估 Cl_rms 23%、Cd 3.6%、St 0.9%** ——
这不是小量，且恰好是"3D 与 2D 差 2%"的量级。换成 16T 后，3D 与 2D 在 β=10%
只差 St 0.01% / Cd 0.4%。因此主协议取 16T，并把 6T 的旧缓存保留作敏感性对照。

测力仍用动量交换法（MEM，只读圆柱反弹链接），尾流仍用**严格两截面守恒亏损**
（只读 ρ/ρu，不做质量守恒化简、不假设 p∞=ρ₀c_s²）；三维截面先对 y 取展向平均，
这与二维的"一条线"是同一条守恒式。

### 13.4 判别逻辑：三个命题，每个都有"若…则…"

1. **Re=100 的三维圆柱是否等价于二维？** 若展向速度 `uz_rel` 随时间衰减到
   1e-6 量级、且 St/Cd 与同分辨率 2D 差 <1%，则 v1.2/v1.3 的 2D 结论不受维度
   怀疑，"β→0 后仍有残余"就只能归给阻塞之外的物理。
2. **展向是否收敛？** 若 St、Cd 在 `nz=8→16→24` 上变化 <1%，则 nz=16 足够；
   若单调漂移，则所有 3D 结论都要标注 nz 依赖。
   > **事后修正**：这条判据本身不够强 —— "<1%" 既可能是"分辨率足够"，也可能是
   > "根本没有三维结构可分辨"。本轮属于后者（§14.4），所以判据要改成"先证明
   > 存在展向自由度（如 Re≳190 或展向强迫），再谈收敛"。
3. **β→0 外推在三维下是否仍口径敏感？** 同一外推口径用于 3D 的
   β=20/10/5% 三点：若 3D 截距比 2D 更接近文献 St 且线性/二次差更小，则 v1.3
   的 ±pp 区间是 2D 约束的直接后果；若 3D 与 2D 截距一致，则残余另有来源
   （数值耗散 / Re 效应），需要换判据。

### 14.2 E20 三维 vs 二维：Re=100 的尾迹就是二维的

3D 跑 `nz=16`，2D 用**完全相同**的 `(nx, ny, D, cx_c, U, Re, 海绵)` 与同一
16T+10T 协议，三档只改域高。每一档给出四个独立读数：St（升力谱）、Cd（动量
交换）、尾流亏损 Cd（严格两截面，只读 ρ/ρu）、展向速度残差 `uz_rel`。

| β | St (3D) | St (2D) | ΔSt | Cd (3D) | Cd (2D) | ΔCd | wake Cd (3D) | wake vs MEM | `uz_rel` |
|---|---|---|---|---|---|---|---|---|---|
| 20% | 0.200075 | 0.200008 | **+0.03%** | 1.7388 | 1.7416 | **−0.16%** | 1.7672 | +1.63% | 1.5e-12 |
| 10% | 0.181153 | 0.181087 | **+0.04%** | 1.5323 | 1.5348 | **−0.16%** | 1.5390 | +0.44% | 1.7e-10 |
| 5% | 0.179400 | 0.179329 | **+0.04%** | 1.5155 | 1.5181 | **−0.17%** | 1.5159 | +0.02% | 1.4e-11 |

四件事同时成立，才允许下"三维就是二维"的结论：

1. **St 三档同号、全部 ≤0.04%**：不是"某一档碰巧对上"，而是随 β 单调同向的
   系统小偏差。0.04% 已低于 St 的数值不确定度（网格/瞬态量级见 §14.5）。
2. **Cd 三档都是 −0.16%**：三维略低，且偏差不随 β 漂移 —— 与"三维多耗散一点
   展向残余动能"一致，量级 1e-3，不影响任何工程结论。
3. **展向速度衰减到 1e-10 以下**：初场不是人为的 z 均匀态 —— `trip=1e-3` 给 `u_y`
   **和** `u_z` 都灌了 `N(0,1e-3)` 的三维随机噪声。跑完 26T 后 `uz_rel` 从 1e-3
   量级衰减 7–9 个数量级，说明 Re=100 的展向扰动被黏性完全抹平，而不是"没被激发"。
4. **独立测力判据同向**：严格两截面尾流亏损与 MEM 的差在 β=10% 是 0.44%，与
   v1.3 §11.2 的 0.4–0.5% 完全一致；β 越小两者越贴近（0.02%），因为两截面近似
   在强阻塞下漏掉的横向动量通量随 β 减小。**β=20% 的 1.63% 是两截面近似的系统
   偏差，不是三维效应**（2D 同档也是 1.63%）。

因此 **v1.2/v1.3 的全部二维结论在 Re=100 不受维度怀疑**。这不等于"三维内核
没有必要"：它把"二维结论成立"从假设变成实测，并给出适用上界 —— 圆柱尾迹的
三维失稳（Mode A）在文献中约 Re≈190，Re=100 距离它还有一个量级的安全余量。
v1.4 首轮看到的"β=10% 差 2.0%"已被证明是 6T 瞬态伪影（§14.5），与维度无关。

> **v1.5 事后修正**：这个上界不是文献推断，已被实测确认并量化——
> 本求解器在 Re=190 上给出近中性的 Mode A 扰动（衰减率仅为黏性值的 1%），
> Re=220/250 翻转成增长并饱和（§17.4）。同时 Re=250 的三维效应是
> **Cl_rms −23%、Cd −3.1%，而 St 只 −0.2%**（§17.1）：所以"二维结论在
> Re=100 成立"成立，但**不能用 St 去外推高 Re 的维度误差**。

### 14.3 E21 β→0 外推：维度差 0.04pp，口径差 6pp

三件事要分开说，否则会把协议差异误读成维度效应：

1. **维度可以排除**：3D 与 2D 的截距差 **0.00007（0.04pp）**，斜率差 2e-5。
   给定同一离散与同一协议，三维不改变 St(β) 的整条曲线 —— 这与 §14.2 的

2. **口径不能排除**：同一个物理问题，两轮的截距相差 **6.1pp**（−4.06% → +2.08%）。

3. **本轮的二次外推没有判别力**：3 个点拟 2 次多项式是**精确插值**（残差 5.6e-17，

   列出来仅作"不要用它"的反例。

把 §14.5 的柱径偏置代进去：用 D=20 的 β=10%/5% 两点（β=20% 按 D 不敏感处理）
重做线性外推，截距从 +2.08% 降到 **+1.05%**。也就是说 6.1pp 的差距里柱径只值
1.0pp，其余 5.1pp 来自域长（15D vs 22D）与瞬态（16T vs 6T）—— 两者都是**协议**，
不是维度，也不是"二维约束"。

残余属于离散/协议误差预算。至于 Re=250 的 +4.71% 是否另有维度来源，本轮
没有三维数据（Re=250 > Mode A 阈值 190，值得单独做），不能顺势否定。

### 14.4 展向 nz 是空判据：没有三维结构可收敛

β=20%、6T 协议，只改展向格点数：

| nz | St | Cd | wake Cd | `uz_rel` | `fz` |
|---|---|---|---|---|---|
| 8 | 0.2001004 | 1.73287 | 1.76248 | 1.9e-7 | 2.9e-13 |
| 16 | 0.2001016 | 1.73260 | 1.76228 | 2.3e-7 | 5.2e-13 |
| 24 | 0.2001007 | 1.73280 | 1.76243 | 7.0e-8 | 1.5e-13 |

三档 St 相差 **6 ppm**（1.2e-6，6 位有效数字内一致），Cd 相差 **150 ppm**
（2.6e-4），展向力 `fz` 全在 1e-13 量级（机器零）。但**这个结果不能写成
"展向收敛性通过"**：

- 初场确实带三维扰动（`trip` 给 `u_y`、`u_z` 都灌 `N(0,1e-3)` 随机数），所以不是
  人为的 z 均匀态；
- 扰动在 16T 内被黏性抹平（`uz_rel` 已到 1e-7），三档 nz 收敛到**同一个二维吸引子**；
- 若真有三维结构，nz=8 与 nz=24 不可能在 1e-6 内一致 —— 8 层根本放不下 Mode A
  的展向波长（约 3–4D）。

**结论：在 Re=100，展向格点数只影响内存，不影响物理。** 想真正检验展向分辨率，
必须进入三维失稳区（Re≳190，Mode A/B）或强制展向变化（展向波浪入口、展向强迫），
本轮不做，列入 §15 的可继续方向。把它写成"nz=8/16/24 收敛"会是**把空判据
当证据**——这与 v1.3 §11.2"CV-link 恒等式不独立"是同一类错误。

> **v1.5 事后修正（两条都成立，但原因不同）**：Re=250 上做的 Lz/D 扫描
> （0.5/1/2/4）显示，**Lz ≤ 2D 三档依然没有任何三维结构，Lz=4D 立刻饱和出
> Mode A**（§17.1）。所以 v1.4 这三档"一致"的直接原因是**盒子装不下**
> （周期盒只允许 λ_z=Lz/m，Lz≤1.5D 的允许波长全部 ≤1.5D），而不是
> "Re=100 太稳"。换句话说：即使把 Re 提到 250，只要不动盒子长度，
> 同样的空判据还会重现。检验展向分辨率需要**同时**满足 Re≳190 与 Lz≳3D。

## §16 v1.5 方法升级：让「展向自由度」变成可测量

v1.4 §15 把 ①②③ 三条并列为可继续方向，但它们是**同一个问题的三个面**：
展向方向在 Re=100 上没有任何可分辨的结构，因此
(a) nz 扫描读不出收敛（§14.4 空判据）、
(b) "2D 约束随 Re 增长"无法检验（Re=250 在 Mode A 之上，但没跑）、
(c) β→0 截距的口径缺口没有单旋钮拆解（§14.5 的 5.1pp 只给了"主因域长/瞬态"）。
v1.5 依次处理这三条，并先把「展向自由度能否被测到」变成可核验的方法问题。

### 16.1 空判据的根源是盒长，不是分辨率

v1.4 的展向扫描用 `nz=8/16/24`，对应盒长 `Lz = 0.5D/1D/1.5D`。周期盒只允许
`λ_z = Lz/m`（`m` 为整数）——**这是本方法最容易自欺的一处**：

| nz | Lz/D | 允许波长 λ_z/D（m=1…） | 装得下 Mode A（3–4D）？ |
|---|---|---|---|
| 8 | 0.5 | 0.5, 0.25, 0.167 | 否 |
| 16 | 1 | 1, 0.5, 0.333 | 否 |
| 24 | 1.5 | 1.5, 0.75, 0.5 | 否 |
| 32 | 2 | 2, 1, 0.667 | 否 |
| **64** | **4** | **4**, 2, 1.33, 1, 0.8 | **是**（m=1 恰在带边） |

也就是说，v1.4 那三档 nz **根本没有一个装得下文献 Mode A 的波长**：它们的
一致不是收敛，而是同一个二维解被三种盒子长度重复采样。这一条写成了纯函数
`representable_wavelengths(nz, d)` 与两条单测
（`test_mode_a_not_representable_in_short_box`、
`test_representable_wavelengths_are_harmonics`），避免以后再拿 Lz=1D 的
扫描当"展向收敛性"。

### 16.2 三个展向口径，只有一个在「零」上可信

| 口径 | 定义 | 优点 | 已知陷阱 |
|---|---|---|---|
| `uz_rel` | 全场 `rms(u_z) / rms(u_x,u_y)` | 与 v1.4 直接可比 | 只看幅值，不看结构 |
| `frac_3d` | `Σ_{m≥1}P_m / Σ_m P_m` | 直观（"多少能量在非均匀模式"） | **机器零时分母也趋零，比值可任意** |
| `p3d_rel` | `Σ_{m≥1}P_m / mean(u_x²+u_y²)` | 与面内动能同标尺，零上稳定 | 需一次额外面内宏量 |

`frac_3d` 的陷阱是实测撞上的：Lz=0.5D、Re=250 的算例 `u_z` 已衰减到
**2.1e-15**，谱却给出 `frac_3d=0.73` —— 因为分子分母都是 1e-32 量级，
比值等于在双精度噪声上做除法。同一点位 `p3d_rel = 1.3e-30`，判为二维。
这条写成单测 `test_machine_zero_is_not_reported_as_three_dimensional`，
并与 `test_uniform_flow_has_zero_3d_fraction`（严格零场必须给 p3d=0）配对：
**一个防谎报三维，一个防把二维当收敛**。

判据门限取 `p3d_rel > 1e-8`：比双精度噪声高 10 个量级以上，又比任何可测的
三维结构（1e-3 量级）低 5 个量级，中间没有可争议的地带。

### 16.3 盒长扫描：只改盒长，不改分辨率

E22 固定 `D=16`、`ny=80`（β=20%）、`nx=320`、`U=0.1`、`Re=250`，只改 `nz`。
因为 `dz` 恒为 1 lu（`D=16` lu），**改变 nz 只改变盒长，不改变每 D 的展向
格点数**——这与"加密展向网格"是两个不同的旋钮，本轮扫的是前者，理由见
§16.1：先要有能装下模式的盒子，谈分辨率才有意义。

配套的**长盒对照**（Re=100、nz=64）是不可省的：若 4D 长盒在 Re=100 上也
"长出"三维结构，那 Re=250 的正结果就只能是数值伪影。这条对照让正结果
可解释，也是 v1.4「判据必须独立」教训的直接应用。

### 16.4 缺口审计：逐级替换，不用拟合

§14.5 的 5.1pp 缺口有四个候选旋钮（瞬态、柱径、点集、域长），v1.4 只做了
"域长 15D→12D"这一条单向测量。v1.5 把 v1.3 的协议**逐级替换**成 v1.4 的
协议，每步只动一个旋钮：

```
A0  v1.3 原样     D=20, 下游 21.5D, 6T, 五点   ← 应复现 −4.06%
A1  瞬态 6T→16T
A2  柱径 20→16（仍 21.5D）
A3  点集 五点→三点（A2 的子集，零成本）
A4  域长 21.5D→15D = v1.4 生产几何
```

链式替换的性质：各步差值**之和恒等于总缺口**，没有归因自由度，也不需要
任何拟合。E24（20D 重跑 β 系列）是另一条独立路径：它只改域长，用来交叉
验证 A3→A4 那一步的方向与量级。

## §17 v1.5 实验结果

### 17.1 E22 盒长扫描：阈值落在 Lz/D = 2 与 4 之间

Re=250、β=20%、`nx=320`、`D=16`，只改展向盒长（dz 恒 1 lu）：

| Lz/D | nz | St | Cd | Cl_rms | `uz_rel` | `p3d_rel` | `fz_rel` | 衰减/黏性 | 末段斜率/步 | 墙钟 |
|---:|---:|---:|---:|---:|---|---|---|---:|---:|---:|
| 0.50 | 8 | 0.22706 | 1.6209 | 0.6603 | 2.1e-15 | 1.3e-30 | 1.1e-15 | +0.44 | +8e-07（机器零） | 3.9 min |
| 1.00 | 16 | 0.22706 | 1.6210 | 0.6605 | 3.2e-08 | 2.3e-17 | 8.1e-16 | +0.50 | −4.2e-04 | 7.9 min |
| 2.00 | 32 | 0.22706 | 1.6210 | 0.6608 | 3.5e-05 | 1.3e-11 | 1.1e-10 | +1.27 | −3.4e-04 | 16.7 min |
| **4.00** | **64** | **0.22629** | **1.5776** | **0.5139** | **4.97e-02** | **7.8e-04** | **2.8e-04** | **−0.31** | **+6.1e-05** | 33.2 min |

三条读数：

1. **Lz ≤ 2D 的积分量五位一致**（St 0.22706、Cd 1.6210、Cl_rms 0.6605±0.0003），
   而展向诊断跨 **10 个量级**（`uz_rel` 2e-15 → 3.5e-5）。这就是 v1.4 §14.4
   空判据的机制：St/Cd 对"盒子里有没有三维结构"**完全不敏感**，拿它们做
   展向收敛判据必然得出"收敛"。
2. **Lz=4D 一档同时出现三件事**：`uz_rel` 饱和到 4.97e-2（是初场 trip 的
   **13 倍**，不是衰减后的残余）、`p3d_rel` 跳到 7.8e-4、展向力 `fz` 从
   1e-10 抬到 2.8e-4；同时 St −0.34%、**Cd −2.68%、Cl_rms −22.2%**。
3. 因此三维效应在这个 Re **不是微小修正，是一阶的**——只是它写在**力幅**
   （Cl_rms、Cd）上，几乎不写在**频率**（St）上。这条读数直接决定
   §17.6 的归因改写。

末段斜率是最硬的判据：Lz ≤ 2D 三档全部为**负**（还在衰减），Lz=4D 为**正**
（还在长），且衰减/黏性比从正号翻成 **−0.31**——不是"衰减得慢"，是**反号**。

### 17.2 长盒对照：同一条 4D 盒子在 Re=100 仍是二维

排除"长盒子自己长出三维结构"的数值伪影解释：

| 算例 | `uz_rel`（末态） | `p3d_rel` | 末段斜率/步 | St | Cd |
|---|---|---|---|---|---|
| Re=250, Lz=4D | **4.97e-02** | 7.8e-04 | **+6.1e-05** | 0.22629 | 1.5776 |
| Re=100, Lz=4D | **5.23e-08** | 1.5e-16 | **−2.7e-04** | 0.20007 | 1.7388 |

同盒子、同分辨率、同协议，只把 Re 从 250 降到 100：`uz_rel` 低 **6 个量级**，
且 Re=100 的 St/Cd（0.20007 / 1.7388）与 v1.4 `nz=16` 的
（0.20007 / 1.7388）**逐位相同**——即 Re=100 下把盒子从 1D 拉到 4D，
积分量与展向结构都不动。

**结论：长盒不是三维结构的来源。** Re=250 的饱和只能来自失稳本身。
这条对照是让正结果可信的必要条件（v1.4 §12 的教训：判据必须独立）。

### 17.3 模式识别：λ_z = 4D 的 Mode A，不是 Mode B

末态展向谱（`P_m / 面内动能`）在三个尾流站位上峰位一致：

| 站位 | `m_peak` | `λ_z/D` | `frac_3d` | `p3d_rel` |
|---|---:|---:|---:|---|
| x/D=3 | 1 | 4.00 | 0.937 | 7.8e-04 |
| x/D=6 | 1 | 4.00 | 0.984 | 5.9e-04 |
| x/D=10 | 1 | 4.00 | 0.979 | 2.7e-04 |

`frac_3d ≈ 0.94–0.98` 说明展向能量几乎全在非均匀模式上，流动已完全三维化；
`p3d_rel` 只有 1e-3 是因为"三维"体现为对二维主流的**调制**，不是取代。

盒长扫描顺便给出了**模式选择性**：Lz=1D 只允许 `λ_z ≤ 1D`（正好覆盖
Mode B 的 0.8–1D 带），它在 Re=250 上**没有**任何结构；Lz=4D 允许
`λ_z = 4D`（Mode A 带 3–4D 的边界），立刻出现饱和三维态。因此本算例的
失稳是 **Mode A**，Mode B 在 Re=250 尚未触发——这与文献（Mode B 起始
Re≈230–260）相容。**v1.6 补充**：把盒子放到 6D 后 Mode B 带（0.8–1.2D）在
Re=250 已能表示，实测占三维能量 **5.6%**（§20.2），所以更准确的说法是
"Mode B 还只是尾支、不是主支"，而不是"完全没有"。

**限制（必须与结论同报）**：波长被盒子钉在 4D 上（m=1 是唯一落在 Mode A
带内的允许模式），所以本实验给不出**自然波长**，只能给"带内某波长被激发"。
要测自然波长需 Lz=6D/8D，本轮的算力不够（见 §18 第 8 条）。
**v1.6 更正**：这里当年还写了"并加展向加密"，是错的——`dz` 已是 0.0625D
（1 lu，`λ=1D` 上 16 点），缺的只有盒长；v1.6 用 `Lz=6D` 未加密即让 Mode B 的
三个 m 都有 13–19 点/λ，详见 §19.4。

### 17.4 E23 失稳阈值：Re=190 近中性，(190, 220] 内翻转

固定 `nz=64`（Lz=4D），扫 Re，与同几何同协议的 2D 逐项配对：

| Re | `uz_rel` 末态 | 衰减/黏性 | 末段斜率/步 | St 3D / 2D | ΔSt | Cd 3D / 2D | ΔCd | Cl_rms 3D / 2D | ΔCl_rms |
|---:|---|---:|---:|---|---:|---|---:|---|---:|
| 190 | 1.36e-03 | **+0.01** | −2.1e-06 | 0.2210 / 0.2209 | +0.08% | 1.637 / 1.642 | −0.29% | 0.5509 / 0.5546 | −0.7% |
| 220 | 7.89e-02 | **−2.02** | −7.2e-05 | 0.2069 / 0.2243 | **−7.74%** | 1.544 / 1.634 | **−5.53%** | 0.4083 / 0.6181 | **−33.9%** |
| 250 | 4.97e-02 | **−0.31** | +6.1e-05 | 0.2263 / 0.2268 | −0.21% | 1.578 / 1.627 | −3.05% | 0.5139 / 0.6652 | −22.7% |

**Re=190 是这一轮最有信息量的一档**：`uz_rel` 停在 1.36e-3（= trip 的 0.37 倍，
即初场对 m=1 的投影份额），末段斜率 −2.1e-6，折算衰减率只有**黏性衰减率的
1%**（`decay/visc = +0.01`）。这不是"衰减得慢"，是**近中性**——若没有失稳
机制，同样这条 4D 盒子在 Re=100 上的衰减率是黏性的 **2.4 倍**（§17.2）。

谱也支持这一点：Re=190 的末态在三个站位都是 `m_peak=1`、`p3d_rel≈1e-6`，
且 `m=2` 比 `m=1` 低 **3–4 个量级**——是单一、干净的 Mode A 扰动，不是
宽带噪声。**本求解器独立给出 Mode A 的临界 Re≈190**，与文献值（190 左右）
吻合。这比 v1.4 的三重解析验证更硬：解析解锁不住失稳阈值。

Re=220/250 都已翻转成增长（`decay/visc` 为负）并饱和，力幅显著下降。
**阈值区间取 (190, 220]**。

两条如实标注：

1. **Re 依赖非单调**：Re=220 的三维态比 Re=250 更强（`uz_rel` 7.9e-2 vs
   5.0e-2，Cl_rms −34% vs −23%，St −7.7% vs −0.2%）。文献里 Mode A 的
   三维能量分数确实在阈值上方先升后降（更高 Re 由 Mode B 接手），本结果
   与之相容；但 10T 记录对慢调制不够长，不能排除统计未收敛。无论取哪种
   解释，"阈值在 190 与 220 之间"这一结论不受影响。
2. **St 不是好探针**：同一套三维失稳，在 Re=250 只改 St −0.21%，却改
   Cl_rms −22.7%。这直接决定 §17.6 对 v1.3 归因的改写。

### 17.5 E24 域长：15D→20D 只值 −0.29pp，「域长是主因」被证伪

2D、`D=16`、`U=0.1`、16T+10T，只把下游从 15D 拉到 20D（`nx=320→400`）：

| β | St 15D → 20D | Cd 15D → 20D | Cl_rms 15D → 20D |
|---:|---|---|---|
| 20% | 0.20001 → 0.20010（+0.05%） | 1.7416 → 1.7418（+0.01%） | 0.3080 → 0.3082（+0.06%） |
| 10% | 0.18109 → 0.18094（−0.10%） | 1.5348 → 1.5327（−0.14%） | 0.2550 → 0.2511（−1.5%） |
| 5% | 0.17933 → 0.17902（−0.18%） | 1.5181 → 1.5159（−0.14%） | 0.2465 → 0.2460（−0.2%） |

三点线性截距：**15D +2.04% → 20D +1.75%（−0.29pp）**。与 E25 的 A3→A4
（+0.39pp）互相印证——**域长在两种独立测法下都只有 0.3–0.4pp**。

因此 v1.4 §14.5 的两句话要改：

- "下游仅 15D，绝对 Cd 比 v1.1 的 20D 域高约 3%"——那是 **D=16/16T 与
  D=20/20T** 两个协议之间的差，混了三个旋钮；在固定 D 与瞬态后，域长本身
  只值 **≤0.2%**。
- "5.1pp 的主因是域长与瞬态"——域长只值 0.3–0.4pp，**主因是瞬态与柱径**
  （§17.6）。

另一条更重要的读数：**五点二次外推给 +11.00%**（20D、D=16），与同一组
五点的线性 +2.10% 差 **8.9pp**；v1.3 的五点二次是 +2.35%（差 6.4pp）。
即 β→0 外推的**函数形式**本身就是 9pp 量级的不确定性来源，比任何物理旋钮
都大。因此"无限域 St"只能报区间，而且这个区间主要由外推形式决定，不是由
CFD 误差决定。

### 17.6 E25 缺口审计：6.1pp = 瞬态 + 柱径 + 域长

逐级替换（每步只动一个旋钮），A0 先复现 v1.3：

| 链 | 协议 | 五点截距 | 三点截距 {20,10,5}% |
|---|---|---:|---:|
| A0 | D=20, 21.5D, **6T** | **−4.06%**（R²=0.964） | −4.03% |
| A1 | 瞬态 → 16T | −1.26%（R²=0.894） | **−0.37%** |
| A2 | 柱径 → D=16（仍 21.5D） | +1.79%（R²=0.880） | **+1.64%** |
| A3 | 点集 → 三点（A2 子集） | — | +1.64% |
| A4 | 域长 → 15D（=v1.4 生产） | — | **+2.04%** |

**A0 的复现是逐位的**：五个 β 点的 St = 0.20017/0.18405/0.17723/0.17265/
0.17123，Cd = 1.7252/1.5311/1.4490/1.4092/1.3948，与 v1.3 表 A/B 的
0.2002/0.1841/0.1772/0.1726/0.1712 与 1.725/1.531/1.449/1.409/1.395
完全一致，截距 −4.06% 与 v1.3 报的数值相同。链的起点可信。

三条链分解（与 v1.4 同点集，三点）：

| 步 | 贡献 | 说明 |
|---|---:|---|
| 瞬态 6T→16T | **+3.66pp** | 6T 把低 β 段的 St 系统性压低（β=5%：0.1712→0.1768） |
| 柱径 20→16 | **+2.01pp** | D=16 在低 β 段 St 更高（β=5%：0.1768→0.1788） |
| 域长 21.5D→15D | **+0.39pp** | 与 E24 的 −0.29pp 互证 |
| 合计 | **+6.07pp** | 总缺口 6.1pp ✓ |

五点链（保留 v1.3 的点集到 A2）给 +2.80 / +3.05 / −0.15（点集）/ +0.39，
合计 +6.09pp。两条链的差别全部落在"点集"一步：三点链把点集的 ±0.2pp
吸收进瞬态与柱径两步。**无论哪条链，域长都只有 0.4pp**。

**误差条（如实标注）**：A1 的低 β 两点不自洽——St(6.7%)=0.17381 而
St(5%)=0.17677，反了。若把 5% 点按趋势修正到 0.1788（=A2 同 β 值），
三点链的瞬态步从 +3.66pp 变 **+4.88pp**、柱径步降到 +1.64pp。因此单步分辨率
约 **±0.6pp**，可下的结论是"瞬态与柱径各占 2–4pp，域长仅 0.4pp"，而不是
"瞬态正好 3.66pp"。低 β 点的不自洽本身也说明：**在 β=5% 上，16T 对 D=20
仍未完全饱和**——这与 §17.5 的"低 β 段外推最不稳"是同一件事的两面。

## §18 v1.5 结论与展望收口

1. **v1.4 的「展向 nz 空判据」被彻底解释：不是分辨率够，是盒子装不下。**
   Lz=0.5D/1D/2D 三档的 St/Cd 五位一致却完全没有三维结构；把盒子拉到 4D
   （唯一能装下 Mode A 波长 3–4D 的选择），立刻出现饱和三维态。因此
   v1.4 §14.4 那句"三档一致不能写成展向收敛"是对的，但它给的替代解释
   （"要 Re≳190"）只对了一半——**还得同时给够盒长**。
2. **Re=250 的三维失稳是 Mode A，阈值在 (190, 220]。** Re=190 的衰减率只有
   黏性值的 1%（近中性）、谱是干净的 m=1；Re=220/250 翻转成增长并饱和。
   本求解器独立复现了文献的 Mode A 临界 Re≈190——这是比解析解更强的内核
   验证（解析解锁不住失稳阈值）。
3. **三维效应是一阶的，但写在力幅上、不写在频率上。** Re=250：Cl_rms
   **−22.7%**、Cd **−3.05%**、St **−0.21%**；Re=220 更强（−33.9% / −5.5% /
   −7.7%）。**v1.3 §11.1 第 3 条的归因要改写**：它用 St 的 β→0 残余
   （Re=250 +4.71%）论证"2D 约束随 Re 增长"——方向对（2D 确实是约束），
   但**指标选错**（St 对三维几乎不敏感）且**量级对不上**（三维只给 −0.2%
   St，而残余是 +4.7%）。该残余仍应归给离散/外推，不是维度。
4. **6.1pp 缺口分解完毕：瞬态 +3.7pp、柱径 +2.0pp、域长 +0.4pp（±0.6pp）。**
   v1.4 §14.5 猜"主因域长与瞬态"——瞬态对了，域长错了（E24 独立测到
   −0.29pp，E25 给 +0.39pp）。柱径 v1.4 完全没考虑，实际占 2pp。
5. **β→0 截距的不确定性主要来自外推形式，不是 CFD。** 同一组 20D 五点：
   线性 +2.10%、二次 +11.00%（差 8.9pp）。可迁移的是"+2% 量级"这个结论
   （15D/20D 三点给 +2.04%/+1.75%），不可迁移的是具体小数。
6. **仪器地板已标定**：Re=100/Lz=4D 的 `uz_rel` 停在 5.2e-8（衰减率 2.4×
   黏性），Re=250 饱和到 5.0e-2——差 6 个量级。因此"没有三维结构"的判定
   下限约 `uz_rel ~ 1e-7` / `p3d_rel ~ 1e-15`，远低于 Mode A 饱和值，
   §17.1 的负结果（Lz≤2D）是可信的。

## §19 v1.6 方法升级：把「Re 依赖」变成可测，并修掉一处网格误记

v1.5 §18 第 8 条把 ①「自然波长与 Mode B」与 ②「Re=300–400 三维」并列，但它们
共用一个前提：**盒子得同时装得下 Mode A 与 Mode B**。v1.6 用 `Lz=6D` 一次满足，
并补两个**跨盒长可比**的读数；同时把 §18 ① 里一条写错的网格建议改正——它会让
后续工作白花 4–6 倍算力。

### 19.1 为什么是 6D：周期盒只能给离散波长，问题是怎么挑

周期盒只允许 `λ_z = Lz/m`。同一支物理模式在不同盒长下落成完全不同的 `m`，
因此**"峰位 m 变了"不等于"物理结构变了"**：

| Lz/D | nz | 允许波长 λ_z/D（m=1…） | Mode A（3–4D）落点 | Mode B（0.8–1.2D）落点 |
|---|---|---|---|---|
| 4 | 64 | 4, 2, 1.33, 1, 0.8 | m=1 → **4D（上边界）** | m=4 → 1D；m=5 → 0.8D（下边界） |
| **6** | **96** | 6, 3, 2, 1.5, 1.2, 1, 0.857, 0.75 | m=2 → **3D（下边界）** | m=5/6/7 → 1.2/1.0/0.857D |
| 8 | 128 | 8, 4, 2.67, 2, 1.6, 1.33, 1.14, 1, 0.889, 0.8 | m=2 → **4D（上边界）** | m=7/8/9/10 → 1.14/1.0/0.889/0.8D |

读法要小心：**6D 并没有"解决"周期盒问题**，它只是让 Mode B 从"一个带边"变成
"三个带内 m"，同时把 Mode A 从上边界 4D 挪到下边界 3D。8D 又能把 Mode A 还原回
4D。于是 `Re=250` 有了一个可归因的三点设计：

```
4D ──λ_A=4D──  6D ──λ_A=3D──  8D ──λ_A=4D──
   ↑ 只差盒长 ──────────────↑         ↑ 只差盒长
        （4D ↔ 8D：λ_A 相同，盒长不同 ⇒ 纯盒长效应）
        （4D ↔ 6D：盒长 + 波长同时变 ⇒ 只能报"合计"，不能归因）
```

没有 8D 那一档，`Re=250` 从 4D 到 6D 的任何差异都无法归因（v1.5 的教训：
判据必须独立）。这一档的成本是单算例约 1 小时，本来指望它换掉一整段"无法归因"
的措辞——结果没换成（见下）。

> **执行结果（如实标注）**：8D 档**没有跑成**。它与主批、2D 配对三进程并行时
> `nz=128` 的吞吐掉到约 2.3 步/秒（预计 2.7 h），且把主批从约 60 min 拖到 73 min；
> 跑到 56.5 min 无产出后主动取消，改用约 1 h（实测 63 min）、能回答"26T 是否定常"的
> Re=250 长窗对照（40T+10T，§20.5）。因此上面这张三点归因图**只完成了两点**，
> 4D↔6D 的差异只能报"盒长 + 允许波长"的**合计**，纯盒长效应留白（§20.3）。
> 更麻烦的是长窗反过来证明 6D 自己在 26T 内没定常 ⇒ 这一格是"三个旋钮里两个
> 没锁住"（盒长/允许波长未分离、窗长未控），不是一个可以下结论的对照。

### 19.2 两个新读数：一个跨盒长可比，一个拓扑独立

| 读数 | 定义 | 解决什么 | 已知限制 |
|---|---|---|---|
| `mode_band_energy` | 把 `P_m` 按**物理波长带**（A:3–4D、B:0.8–1.2D）汇总 | 换盒长后仍可比；给出两支的能量占比 | 只回答"带内有多少能量"，不回答"带内哪个波长占优" |
| `spanwise_correlation` | 循环两点相关 `R(r)`、积分尺度 `L_c = Σ_{r<r0}R(r)` | 物理空间读数，换盒子不改形状 | `r0` 用首个过零点，双模式叠加时 `L_c` 只是有效尺度，不是某个波长 |

两个都写成纯函数并配单测。相关的三条不变量：纯正弦 `R(r)=cos(2πmr/nz)` 逐点
相符、`r0 = nz/4m`、`L_c` 随 `m` 单调下降。**必须先去展向均值**：不减的话 m=0
直流项把 `R` 钉在 1，`r0` 直接跑到半盒长——单测
`test_mean_removal_kills_dc` 用"带直流偏置的正弦"把这条钉住，因为二维流动正是
"只有直流项"的极端情形，一旦漏减就会把二维读成"超长相关"。

`mode_band_energy` 带一个 `repr_ok` 字段：某个带在本盒长下**没有任何可表示的 m**
时置 False。此时"带内能量为 0"是盒子造成的，不是物理结论——这是 v1.4 空判据的
同类陷阱，单测 `test_bands_disjoint_at_6d_but_not_at_1d` 用 `Lz=1D` 把它固定下来
（1D 盒里 Mode A 的 3–4D 无任何代表，Mode B 只有 m=1）。

### 19.3 饱和律：两种拟合 + 一个无模型读数

目标量取 `E(Re) = |ΔCl_rms| / Cl_rms,2D × 100`。**不用 St**：v1.5 实测三维对 St
只有 0.2–0.3% 的影响，对 `Cl_rms` 有 22%，用 St 当探针等于把信号缩小十倍。

- 幂律 `E = a·((Re−190)/110)^b` 与线性两种拟合都报，`b` 与 `R²` 并列；
  4 点 2 参数只剩 2 个自由度，`R²` 只作参考、不当证据；
- **无模型读数** `E(400)/E(250)` 才是主判据：饱和 ⇒ ≈1，线性 ⇒ ≈3.5。
  它不依赖任何拟合形式，v1.5 已经吃过"外推形式差 8.9pp"的亏。

### 19.4 修正 §18 第 8 条 ①：展向分辨率从来没缺过

§18 ① 写"展向加密到 `dz=0.125D`（Mode B 的 λ≈1D 才有 8 格）"。这是**错的**：
v1.5 的 `dz` 恒为 1 lu，而 `D=16` lu ⇒ **`dz = 0.0625D`**，`λ=1D` 上有 **16 个
格点**，早就超过 8 格。`dz=0.125D` 比现状**更粗**——这句话是把 v1.4 的旧网格
（`nz=16` 时 `dz=0.25D`）记串了。

真正缺的只有盒长。本轮 `nz=96` 仍在 `dz=1 lu` 上跑，Mode B 的三个可表示 m 分别有
**19.2 / 16 / 13.7 点/λ**（λ=1.2/1.0/0.857D）。把这条写进报告，是为了避免后续
按错的建议去加密展向、白花 4–6 倍算力却什么都没检验到。

展向力系数 `fz_rel` 同步从 1.1e-4 涨到 9.3e-4（8 倍），说明三维结构不只是"存在"，
而是越来越强地参与动量交换。

**必须加的注脚（见 §20.5）**：上表是 **26T** 的读数，而 Re=250 的 26T 结构量是
**瞬态**——把窗拉到 50T，它的谱重心 2.44 → **3.74**、特征波长 2.46D → **1.60D**、

**"高 Re 端的展向尺度更短"**，不是"随 Re 单调律"。

  没做到。

> "26T 的 6D 解处在 m=1 增长期，50T 后落到 m=2，模式选择的时间尺度 > 26T"。
> 相应地，v1.5 的 `ΔSt=−0.34%`、6D@26T 的 `−2.77%`、6D@50T 的 `−0.76%` 是同一个
> 量的三个读数——**0.3%~2.8% 就是 St 三维修正目前的区间**；"8 倍"是窗长未受控
> 造成的假精度，一并撤回。

**限制（必须与结论同报）**：6D 相对 4D 同时改了盒长与 Mode A 的可表示波长
（4D → 3D），两者在本轮**无法分离**。原计划的 Lz=8D 档（把 λ_A 还原成 4D）因
算力排程被取消——三个重进程并行时 `nz=128` 的吞吐掉到约 2.3 步/秒（预计 2.7 h），
与其拖慢主批不如放弃，如实标注为未做项。加上窗长未受控（只有 6D 跑了 50T），
4D↔6D 这一格有**三个旋钮**里的两个没锁住。

### 20.4 饱和律：两个量的答案不同

| 量 | 4 点取值（Re=250→400） | 幂律 b（R²） | 线性 R² | 无模型 `E(400)/E(250)` |
|---|---|---:|---:|---:|
| `ΔCl_rms` 相对跌幅 | 15.9 / 40.9 / 57.2 / 72.9 % | 1.22（0.965） | 0.986 | **4.59** |
| `ΔCd` 相对偏差 | 2.37 / 5.20 / 7.08 / 8.59 % | **1.04**（0.970） | 0.979 | **3.63** |
| `ΔSt` 相对偏差 | 2.77 / 0.77 / 1.06 / 3.07 % | −0.08（无意义） | — | — |

- **`Cd` 的三维修正随 `(Re−190)/110` 近似线性增长**：`b=1.04`，无模型比值
  3.63 对照线性预测 3.50（差 3.6%）。这条**没有饱和**。
- **分母换成 50T 的 Re=250，结论不变**：`E_cd(250)` 2.37% → **2.09%**、
  `E_cl_rms(250)` 15.9% → **15.7%**；`E_cd(400)/E_cd(250)` 3.63 → **4.10**、
  `b` 1.04 → **1.14**（R²=0.949）；`E_cl_rms` 比值 4.59 → **4.65**、`b` 1.22 → **1.23**。
  两个分母下 `Cd` 的比值都**不低于**线性预测、`Cl_rms` 都远离 1 ⇒ "不饱和"不依赖
  窗口长度（这也是把长窗算例写进脚本而不是只写进文字的原因）。
- **`Cl_rms` 的"b=1.22"是伪幂律**：它的相对跌幅有**天然上界 100%**（升力脉动
  全丢）。有界量在接近上界时 log-log 斜率必然 >1 再回落到 0，用幂律拟合会给出
  一个没有物理含义的指数。正确的读法是**趋界**：−15.9 → −40.9 → −57.2 → −72.9%，
  逐点增量 −25.0 / −16.4 / −15.6pp 在收窄。
- **`St` 的拟合不该做**：四点非单调，任何单调模型都是硬套。如实报原值。

结论：**"3D 效应饱和"只在 v1.5 的单点、单盒里看起来成立**。把 Re 拉成四点看，
力幅偏差（`Cd`）线性增长，升力脉动趋向上界——是"继续变"而不是"停住"。
这也解释了为什么 v1.3 当年"残余随 Re 增长"的直觉并非全错：方向对，但量级
（−8.6% 的 Cd 在 Re=400）仍远小于它当年要解释的 6.1pp 协议缺口。

### 20.5 Re=250 的定常性：26T 恰好停在瞬态峰值上

只有 Re=250 值得查：它 26T 窗内的 `uz_rel` 从 0.034 单调涨到 0.087，而
Re=300/350/400 的末 20 帧斜率只有 −1.2e-4 ~ −4.3e-5/帧（比 Re=250 的
+2.2e-4/帧小一个量级）。同几何、同初场协议，把瞬态从 16T 拉到 40T、记录窗
仍 10T（墙钟 63 min）：

| 量 | 26T（16T+10T） | 50T（40T+10T） | 相对差 |
|---|---:|---:|---:|
| `St` | 0.22048 | 0.22505 | **+2.07%** |
| `Cd` | 1.58866 | 1.59312 | **+0.28%** |
| `Cl_rms` | 0.55958 | 0.56098 | **+0.25%** |
| `uz_rel` | 4.981e-02 | 3.952e-02 | **-20.67%** |

- **力幅已经定常**：`Cd` **+0.28%**、`Cl_rms` **+0.25%**；
- **频率没定常**：`St` **+2.07%**，比 Re=250 的整个三维修正量
  （−2.77%）还大；
- **三维幅值与模式没定常**：`uz_rel` **-20.67%**、`p3d_rel` 掉 3.2 倍。

结构量换了一整套：

| 结构量 | 26T | 50T |
|---|---:|---:|
| `m_peak` | 1（λ=6D） | **2（λ=3D）** |
| 谱重心 `m` | 2.44 | **3.74** |
| 特征波长 /D | 2.46 | **1.60** |
| A 带（3–4D）占比 | 0.202 | **0.422** |
| B 带（0.8–1.2D）占比 | 0.056 | **0.239** |
| `L_c`/D | 0.441 | **0.303** |
| `p3d_rel` | 3.1e-3 | **9.7e-4** |

**最直接的证据是时程**：26T 档的 `uz_rel` 最大值 **0.0868 出现在 t=26.2T**，
也就是记录窗的**最后一帧**；50T 档显示它随后在 24T 内衰减回 **0.0345**
（末 10 帧均值 0.0345，末 20 帧斜率 0）。所以 26T 窗记录的不是
"饱和三维态"，而是**起振段**：长波（m=1，λ=6D）先长起来，50T 后让位给
Mode A 的 m=2（λ=3D），A 带占比翻倍、B 带涨 4 倍、`L_c` 缩到 0.30。

**对前面四节的影响（逐条）**：

1. §20.1：Re=250 的 `ΔCd`/`ΔCl_rms` 经长窗复核（0.28%/0.25%）**可信**；`ΔSt` 要按
   ±2% 读，"−2.77%"不应单独引用。
2. §20.2：Re=250 的 26T 结构量是瞬态（重心 2.44→3.74、波长 2.46D→1.60D），
   "随 Re 单调缩短"**降级**为"高 Re 端更短"。
3. §20.3：盒长效应（−2.56%）与窗长效应（+2.07%）同量级，4D↔6D **不可归因**；
   "偏好 λ≥6D"撤回。
4. §20.4：把 Re=250 换成 50T 读数重算，`E_cd(400)/E_cd(250)` 3.63 → **4.10**
   （线性 3.50、b 1.04 → **1.13**，R²=0.949），
   `E_cl_rms` 比值 4.59 → **4.65**（b 1.22 → **1.23**）
   ⇒ **"不饱和"不依赖分母**，这是本轮少数经得起换分母的结论。

**限制**：① 只有 Re=250 做了长窗；Re=300/350 的 `uz_rel` 分位均值也在涨
（0.055→0.080、0.069→0.078），只是幅度小，**没有**长窗对照，不能假定它们已定常；
② 40T 只是"更长"，末 10 帧内 `uz_rel` 仍从 0.0340 漂到 0.0347（**+2.2%**），
不构成收敛证明；③ 63 min/档的成本决定了不能对四档都做，因此 §20.1 的表格仍是
26T 读数——**这一节的作用是给出它的不确定度，不是替换它**。

| Re | τ | ρ_min（流体） | ρ_max | `u_max` | finite |
|---:|---:|---:|---:|---:|---:|
| 250 | 0.5192 | 0.9681 | 1.0189 | 0.161 | ✅ |
| 300 | 0.5160 | 0.9657 | 1.0187 | 0.160 | ✅ |
| 350 | 0.5137 | 0.9587 | 1.0186 | 0.167 | ✅ |
| 400 | 0.5120 | 0.9588 | 1.0185 | 0.178 | ✅ |

四个算例全程有限、密度正、速度不超过 0.18（Ma≈0.10）。Re=400 的 τ=0.512 已经
低于 v1.1 标定的 `τ≤0.53` 红线，但那是 v1.0 的协议（Zou/He + 对流出口 + 半程
反弹）；现协议（Bouzidi 亚格反弹 + 目标态海绵）在 0.512 上跑满 26T 无异常。
**这只是"没炸"，不等于"精度够"**：τ 越小，BGK 的离散误差越大，Re=400 的绝对
Cd 是否会因此偏低，本轮没有独立判据（没有 DNS/实验对照），只能标为未验证。


## §21 v1.6 结论与展望收口

1. **三维效应随 Re 加深，主体是「展向去相干」而不是「幅度修正」。**
   `Cl_rms` 相对二维从 **−15.9% 一路掉到 −72.9%**（Re=250→400），`Cd` 从 −2.4%
   到 −8.6%。到 Re=400，三维尾迹的升力脉动只剩二维的 27%。这两个量在 Re=250
   经 50T 长窗复核（`Cd` +0.28%、`Cl_rms` +0.25%），**力幅层面的结论是稳的**。

2. **「St 对三维不敏感」要按窗长与盒长一起改写。** 同一个量有三个读数：
   4D@26T **−0.34%**、6D@26T **−2.77%**、6D@50T **−0.76%**。所以能说的是
   "St 的三维修正在 **0.3%–2.8%** 区间、比 `Cl_rms` 小一个量级以上"，不能说
   "8 倍"——那是窗长未受控造成的假精度。

3. **v1.5 的 4D「饱和值」既被盒子压制、也被窗长污染。** 同 26T 窗下 4D→6D 值
   **St −2.56%、Cd +0.70%、Cl_rms +8.89%、`p3d_rel` ×3.9**，而 6D 自己把窗拉到
   50T 又值 **St +2.07%**——**盒长效应与窗长效应同量级**，这一格无法归因。
   原计划的 8D（纯盒长）与"四档都跑 50T"都没做，如实留白。

4. **本轮最重要的是一条负结果：26T 恰好停在瞬态峰值上。** Re=250 的 `uz_rel`
   最大值 **0.0868 出现在 t=26.2T**（记录窗最后一帧），50T 后衰减到 0.0345，
   谱峰从 m=1（λ=6D）换到 m=2（λ=3D），A 带占比 0.20→0.42。⇒ **"收敛"必须
   分量说**：力幅（Cd/Cl_rms）先定常，频率（St）与模式组成后定常。任何"谱/波长"
   结论都必须注明窗长——这一条比本轮任何一个数字都更该被后续工作继承。

5. **峰位不是特征波长，谱重心也会随窗长动。** `m_peak` 在 1/2/4/1 之间跳；
   重心在 26T 是 2.44→4.04，但 Re=250 拉到 50T 后是 **3.74**（不是 2.44）。
   所以"随 Re 缩短"只能降级为"**高 Re 端（300–400）展向尺度更短**"，
   单调律不成立；两点相关的 `L_c/D` 同样从 0.44 变到 0.30。

6. **饱和律：不饱和，且这个答案不依赖分母。** `E_cd(400)/E_cd(250)` 在 26T
   分母下 **3.63**、50T 分母下 **4.10**（线性预测 3.50），幂律 `b` 1.04/1.14；
   `E_cl_rms` 4.59/4.65，`b` 1.22/1.23。两个分母下 `Cd` 都不低于线性、
   `Cl_rms` 都远离 1 ⇒ "3D 效应会继续长"是稳的；而 `|ΔCl_rms|` 的 `b=1.22`
   属**有界量的伪幂律**（增量 −25.0/−16.4/−15.6pp 收窄），不报指数。

7. **`τ=0.512` 可用，但精度未验证。** Re=400 的 τ 已低于 v1.1 的 `τ≤0.53` 红线，
   而现协议（Bouzidi + 目标态海绵）跑满 26T 全程有限、`ρ_min` ≥0.959、
   `u_max` ≤0.178。**"没炸"不等于"够准"**：BGK 在低 τ 的离散误差没有独立判据，
   Re=400 的绝对 Cd 是否偏低属未验证项。

8. **方法学订正三处**：① §18①/工作记录 §10.1 的"展向加密到 `dz=0.125D`"是错的
   （`dz` 已是 0.0625D，λ=1D 有 16 点），缺的只有盒长，见 §19.4；② 峰位不能当
   特征波长，改用谱重心，见 §20.2；③ **窗口长度是第三个旋钮**，26T 的谱/模式
   读数会随窗长变，见 §20.5。

9. **复现与产物**：`bash run_all.sh`（00→14，不含可选的 `--long250`）；
   **125 项单测全绿**（112 + 13）；`results/v16_highre.json` / `v16_case_rows.csv`，
   图 `v16_highre.png` / `v16_spanwise_corr.png` / `v16_box_compare.png`。
   墙钟：3D 四档 73/59/72/58 min（两进程各 12 线程并行，总 2 h 13 min）、2D 配对
   5 min、长窗对照 **63 min**。

10. **可继续方向**（按优先级，成本都是本轮的 2–6 倍）：
    ① **把窗长锁住**：四档都跑 40T+10T（约 4×63 min）——这是唯一能把 §20.2/§20.3
      里"随 Re"的说法救回来的办法，也是本轮暴露的最大方法学缺口；
    ② **纯盒长**：`Lz=8D`（nz=128，需单独排程不抢核）把 λ_A 还原成 4D；
    ③ **Re≥500**：验证 `Cd` 的线性律是否外推、`Cl_rms` 是否真的贴到上界；
    ④ **低 τ 的精度校准**：固定 Re、改 `U` 或 `D` 做 τ 扫描，把 BGK 离散误差与
      物理效应分开（本轮唯一"跑得动但说不准"的地方）；
    ⑤ 振荡圆柱（受迫 / VIV）与串列 / 并列双圆柱干涉。


## §22 v1.7 把窗长锁住：Re × 窗的二维矩阵

### 22.1 为什么不是"补四个 50T 终点"

v1.6 §20.5 只在 Re=250 上做了一次 26T→50T 对照，发现记录窗恰好停在 `uz_rel`
的瞬态峰值上（0.0868 @ t=26.2T），50T 后掉到 0.0345，谱峰从 m=1 换到 m=2。
那是一条很强的负结果，但它只是**一个 Re、一个长窗**的孤证，不能回答三个更要紧的问题：

1. 峰值时刻是否随 Re 移动？若 Re=350 的峰值在 40T，则 26T 与 50T 两个窗都会误判；
2. 力幅、频率、模式组成各自的定常时间尺度是否不同？v1.6 只看到 Re=250 的"力幅先定常、频率后定常"；
3. 26T 下"三维效应随 Re 加深"的趋势，在更长窗下是否还在？

本轮的做法是：**一档跑满 50T，全程记录力系数与 `uz_rel`，切成 5 个 10T 窗**，
每个窗单独归约 St/Cd/Cl_rms/谱重心/模式带占比/两点相关/峰值时刻。
成本与只跑一个 50T 终点完全相同（约 63 min/档），但产出从四个数变成
`Re × 窗` 的二维矩阵。

### 22.2 协议、口径与分辨率

协议与 v1.6 **逐项一致**：nx=320、ny=80、D=16、β=20%、Lz=6D（nz=96）、
40T 瞬态 + 10T 记录、`UZ_EVERY=400`。唯一新增的自由度是"记录窗的位置"。

三条口径必须随数字一起报：

- **St 的窗间分辨率**：10T 窗的 FFT 频率间隔 `ΔSt ≈ 1/(10T)·D/U ≈ 0.022`，
  Hann 窗 + 抛物线插值细化后约 0.005。但 Re=250 实测五个 10T 窗的 St 是
  **0.2288 / 0.2233 / 0.2156 / 0.2255 / 0.2250**，窗间差达 **6%**——
  远超纯谱分辨率。原因是中段窗还含起振/模式切换（见 §22.3），非平稳信号下
  "主频"本身在移动。判读时只有**后两窗**（结构与力都趋稳）之间的差才可读，
  前段窗的 St 只作为"频率也在演化"的证据，不用于趋势拟合。
- **谱与相关取窗末瞬时快照**（与 v1.6 记录窗末的口径一致），不是窗内平均；
  它们描述的是"该窗末的流场结构"，不是"该窗的平均结构"。
- `force3()` 只读求解器缓存的力，不改变流场。Re=250 的 50T 记录窗统计可与
  v1.6 长窗缓存**逐项交叉核对**（§22.6）；若不一致，说明采样器有副作用，整批作废。

稳态判据只用"相对参考窗的漂移 <2%"作**判读辅助**，不是收敛证明（v1.6 §20.5 的教训：
窗末局部斜率≈0 也可能正站在峰值上）。真正的判据是"峰值时刻是否落在窗内"。

但"没炸 ≠ 够准"的限定不变（低 τ 的 BGK 离散误差仍无独立判据）。

**结论一：窗长锁不住高 Re 的三维瞬态，这是本轮最重要的负结果。**
`uz_rel` 峰值时刻 Re=250 为 **26.2T**、Re=300 为 **29.6T**、Re=350 为 **48.8T**
（落在最后一个窗）、Re=400 为 **20.1T** 但**五个窗的峰值都在 0.087–0.099**
（全程高位反复起落）。窗均值同样如此：Re=250 从 0.064 衰减到 0.039，
而 Re=350/400 末两窗仍停在 **0.081 / 0.086**。⇒ 50T 只够低 Re 走完起振—衰减，
高 Re 的三维结构在 50T 内没有稳定平台。**v1.6 §20.5"力幅已定常"只在 Re=250 成立**，
推广到 Re=350/400 是过度外推。

**结论二：但"三维效应随 Re 加深"这个趋势本身是稳的。**
§22.5 显示 `Cl_rms` 相对二维的跌幅在窗1–窗4 全部**单调加深**
（Re=400 从 70.3% 到 72.3%），末窗 −15.7/−36.9/−64.0/−72.3% 与 v1.6 26T 的
−15.9/−40.9/−57.2/−72.9% 同向且量级一致；`Cd` 的 250→400 跌幅在五个窗里
稳定在 −7.6% ~ −8.2%。⇒ **趋势可信，绝对值带窗长误差**：不能把某一个窗的
跌幅当成"定态值"，但可以肯定高 Re 的三维力幅代价更大。

**结论三：St 对三维不敏感，且这个结论跨窗成立。**
末窗的三维−二维 St 差是 **−0.76 / +0.07 / −0.40 / −0.87%**，全在 ±1% 内；
前段窗虽有 −3.8% 的读数，但那落在起振段（§22.2 已说明非平稳信号下主频本身在移动）。
⇒ v1.6 §21 第 2 条"St 修正 0.3%–2.8%"应收敛为：**定态附近约 ±1%，
起振段可达 −4%**；用 St 当三维探针仍然选错指标。

**结论四：谱/相关这类结构量在早期窗不可信，必须等模式选稳。**
Re=250 的 A 带占比窗0=0.929、窗1=0.024（几乎相反），谱重心 1.98→3.82；
Re=300 的谱重心甚至从 5.0 一路降到 2.9。初场残余与起振共同造成前两窗的
谱不可用于物理判读。**只有后两窗（40–50T）的结构量可跨 Re 比较**，
且此时四档谱重心 3.74/3.21/3.18/3.19 已相当接近 —— v1.6 声称的
"高 Re 端展向尺度更短"在 50T 窗口下**不再成立**，应撤回，
改为"模式组成在 50T 后才趋同（m≈3.2–3.7），前段窗的差异是瞬态"。

**方法学产出**：采样器通过 Re=250 50T 交叉核对——Cd/Cl_rms/St 三项与 v1.6
缓存**逐位相同**（绝对差 0.0），证明每步 `force3()`、窗末谱采样与定期 gc
都不改变流场。这是"同一流场、多把尺子"最干净的验证方式，值得在后续版本复用。

**未做项（如实标注）**：① 四档都只到 50T，Re=350/400 的瞬态仍未走完，
需要 80–100T 才能定论（约 4×2.5 h）；② `Lz=8D` 纯盒长档仍未做，
4D↔6D 的盒长与允许波长两个旋钮依旧分不开；③ 低 τ 精度校准未做。

### 23.7 判读与未做项

**结论一：100T 仍没有"锁定平台"，而且 Re=400 的全局峰值从 20.1T 后移到 75.8T。**
v1.7 在 50T 内看到 Re=400 的峰值是 20.1T、五个窗都高位起落；延长到 100T 后，
真正的全局峰值出现在 **75.8T / uz_rel=0.1009**，比 50T 前的读数还高，
末窗仍是峰值的 **85.9%**。Re=350 的峰值仍在 48.8T（0.0971），末窗为峰值的
**79.0%**；它的末 3 窗斜率 −0.00102/窗、30T 只降 **2.58%**，按这个速率
要再跑上千个 T 才能到 Re=250 的 0.039 平台。因此 Re=400 的自动判据给
`persistent_high`，Re=350 给 `decaying`，但后者只是被 0.8 的比值阈值卡住：
**两档都不是"已收敛"，Re=400 甚至是"越跑峰值越高"**。
⇒ v1.6 §20.5"力幅已定常"的适用范围进一步收窄为**仅 Re=250**；
v1.7 §22.7 的"高 Re 瞬态未走完"现在有了明确答案：**不是窗不够长，是非定常在持续**。

**结论二：三维效应是持续振荡带，不是一个可以报出的定常值。**
Re=350 的 3D−2D `Cl_rms` 跌幅在十个窗里从 −52.7% 摆到 −64.0%，末窗 −59.0%；
Re=400 从 −54.9% 摆到 −74.7%，末窗 −68.9%。`Cd` 的跌幅则稳定得多
（Re=350 −6.3%~−7.8%，Re=400 −7.1%~−8.5%），`St` 差基本在 ±3% 内。
后半程两块相比：Re=350 的 `Cl_rms` 只差 −2.67%，Re=400 却差 **−15.22%**，
而 Re=400 的 `uz_rel` 块均值反而 **+5.40%** —— 力幅与三维强度的后半程
走向相反。**v1.7 说"趋势可信、绝对值带窗长误差"过于温和：那是持续振荡，
不是收敛前的残差**。可安全引用的只有"高 Re 的三维力幅代价更大"这个方向；
任何单点跌幅都应带窗号。

**结论三：低 τ 不是高 Re 三维效应的解释。**
τ=0.505–0.55 的剪切波反测 ν 相对偏差稳定在 **0.32%**，不随 τ→0.5 发散；
Re=400 的 τ=0.512 只对应有效 Re=398.72（偏移 −0.32%）。
3D 造成的 `Cd` 差约 8%、`Cl_rms` 差几十个百分点，比数值误差高一个量级。
⇒ v1.1 的 τ≥0.53 红线是**稳定性**经验，不是**精度**判据；把 Re=400 的
三维效应归咎于低 τ 是错的。但本轮只给误差预算，未在 τ=0.512 下直接复算 Re=400
（那要同时改 U 与 D，属于另一个实验）。

**方法学产出**：交叉核对必须写明分界。前 40T 四窗的 Cd/Cl_rms/St 与 v1.7
**逐位相同**（绝对差 0）；40–50T 窗因 v1.7 把 1 步尾窗并入而差 1–2 步，
实测 Re=350 的 Cd/Cl/St 相对差 3.1e−5% / 1.4e−3% / 1.0e−2%，
Re=400 为 2e−4% / 5.1e−3% / 5.5e−3%。若照搬 v1.7 的措辞写
"前 50T 逐位相同"，就是一个用词错误——虽然数值差很小。

**未做项**：① `Lz=8D` 纯盒长仍未做，4D/6D/8D 三点分离不了盒长与允许波长；
② 既然 100T 仍不锁定，继续拉长窗的边际收益很低，下一步应改强迫/边界
（例如去掉入口 trip、换滑移长度）而不是把 100T 拉到 200T；
③ 低 τ 只做了解析剪切波预算，未做 Re=400 的低 τ 直接复算。

### 24.4 判读与边界

**判据是预先登记的，阈值在看见消融结果前已固定**（幅值不敏感带 [0.75, 1.25]、
峰值明显移动 ≥4T、零扰动双读数 <1e−8、e-folding 相对误差 ≤60% 或 ≤1 个窗宽）。
用 v1.8 基准档的起振增长率 g≈0.0811/T 先验预测：幅度降 10× 应把峰值推迟
ln(10)/g≈28.4T（即约 104T，略超出本轮 100T 记录窗），幅度升 10× 应提前约 28T。
这使"小扰动档晚期没追平"不能直接当成"强迫维持"——必须先看峰值平移是否与
该预测同量级。

**结果（全部从 `results/v19_forcing.json` 取数）**：基准 70–100T 的 uz_rel 均值
0.08809；trip=1e-4 为 0.08058（**91.5%**）、trip=1e-2 为 0.08373（**95.0%**）、
种子 43 为 0.08260（**93.8%**），三者都落在预先登记的 [0.75, 1.25] 带内。
对应 Cd 比 **1.0047 / 1.0041 / 1.0026**、St 比 **0.9920 / 0.9970 / 0.9903**，
即力幅与频率几乎不随初场幅度/ realization 改变；Cl_rms 比
1.149 / 1.163 / 1.112 稍高，但 v1.8 已证明 Cl_rms 逐窗摆动可达十几到二十个百分点，
三窗均值受相位影响，不能据此判"另一个吸引子"。零扰动档 50T 内 uz_rel
**1.07e−16**、p3d_rel **0.0**，双读数机器零 ⇒ 没有初场种子时不起三维。
联合判据 **`self_sustained_attractor`**（幅值不敏感=真、峰值不同=真、零扰动二维=真）。

**一个必须写清的反面读数**：三档的"全局峰值时刻"分别为 23.1T / 5.0T / 12.1T，
与基准 75.8T 相差 −52.7 / −70.8 / −63.8T；预先登记的 e-fold 预测
（ln(幅度比)/增长率）只对 trip_hi 同量级，对 trip_lo 完全不符。原因是这里的
"峰值"是全程最大值，而 Re=400 的 uz_rel 本来就在 0.08–0.10 间多峰反复起落：
trip_hi 的 5.0T 峰值是**大初场自身的初始脉冲**，trip_lo 的 23.1T 是早期峰，
基准的 75.8T 是后期略高的另一峰。它们不是同一个物理事件的"点火时刻"。
因此**峰值平移只用来证明"轨迹不同"，不用来推断"被强迫维持"**；
真正的判据是晚期饱和幅值、Cd/St 与零扰动对照三者联合。
同理，表中"起振增长率"用 t=2–25T 的 log(uz_rel) 拟合：基准的 0.0811/T
落在干净的指数段，而 trip_lo 的 0.1893/T 与 trip_hi 的 0.0144/T 分别被
早期饱和与初始脉冲污染，**只作诊断项，不参与幅值判据**。

**边界与限度**。第一，`trip` 是 t=0 的一次性初场扰动，不是持续随机强迫；
本消融能检验的是"非定常状态是否依赖特定初场 realization / 边界条件"，
不能穷尽所有可能的持续扰动源。第二，零扰动档只说明**没有初场种子时不起
三维**，不能外推成"流动永不相干"；真正的判据是换种子/换幅度后的饱和态。
第三，无滑移壁档本轮未跑（会同时改变有效阻塞比），不能把自由滑移写成
"维持非定常的必要条件"。第四，10T 窗的峰值时刻分辨率约 ±5T，
峰值平移的定量比较只到"同量级/明显不同"，不做小数点估计。
