## §2 求解器设计

- D2Q9 + BGK（Mocz 速度序），f_eq = wρ(1+3cu+4.5cu²−1.5u²)；ν=(τ−0.5)/3，Re=UD/ν。
- **半程反弹**（link-wise）：f_ī(x_f,t+1)=f_i*(x_f,t)（比教学版的固体节点全反弹更准）。
- **动量交换测力**：F=2 Σ_{圆柱链接} e_i f_i*（反弹时 f_i* 暂存于 ī 槽位）；只统计圆柱链接，避免壁面力污染。
- **边界**：西 Zou/He 速度入口（ux=U,uy=0，解析解 f2/f3/f4）；东一阶对流出口；顶底自由滑移（镜面反射，cx 不变 cy 反向）。
- numba JIT 核（`kernels.py`）与 numpy 路径逐步对照一致（max diff 8e-16），步耗时 54→9 ms（400×200，6× 提速）。

## §3 调试战记（核心坑）

1. **降采样混叠毁掉 St**：力信号宽频噪声 + `record_every=5` 无抗混叠 → FFT 主峰跑到 St=2.75（真值 0.167）。`record_every=1` 后 St=0.174（+4.6%），过零/自相关/谱三方一致（T≈690 步）。教训：**力时程必须逐步记录或先低通再降采样**；`strouhal()` 加 dt 参数显式化采样间隔。
2. **固体节点 ρ=0 除零**：macros 产生 nan → feq nan → roll 扩散进流体。安全除法（ρ≤0 时速度置 0）后清零固体。
3. **测力必须限定圆柱链接**：no_slip 顶底时壁面链接会混入 x/y 方向力。
4. 小域快测（圆柱离入口 3.75D）给出误导性 St——入口须 ≥6D、记录须 ≥20 个周期。
5. wheel 文件名缺 abi 段（`cp312-cp312`）→ pip "Invalid wheel filename"。
6. **低 τ 边界泵能发散（本项目最大坑）**：U=0.08/D=20（Re=150/200 时 τ=0.532/0.524）整域指数爆炸（|u| 0.1→5500，it=500→1000）；Re=100（τ=0.548）虽不炸但力信号被宽频噪声主导（cd 中位 0.27、std 4.8、步间跳变 0.19）。二分定位：
   - 纯周期 BGK τ=0.5288 完全稳定（扰动衰减）→ 核心无罪；
   - 出入口 + 圆柱反弹 + 顶底边界任意组合在 τ≲0.53 全炸，no_slip 更快；
   - 结论：**Zou/He 入口 + 对流出口 + 反弹的边界组合在 τ≲0.53 泵能**。修法：抬 τ≥0.54（U=0.1、D=28 → τ=8.4/Re+0.5 ∈ [0.542, 0.668]，Ma=0.17），Re=100 力信号恢复健康（Cd 1.32、|ΔCd| 0.013）。
   - `run_transient` 加发散守卫（|u|>1 即抛错指认 τ）。
7. **高 Re 长时力慢波污染（v1.0 收口诊断）**：Re=50 全程干净；Re≥100 瞬时 Cd 随时间腐败（负值占比升至 ~50%、慢漂 ±2），但 **St/Cl 稳健**。诊断链：
   - 尖峰逐节点抓拍（Re=200, it≈22513, 瞬时 Cd=6.06）：264 链接单点贡献全部 ±1.78 内物理正常（上游 dir=3 ≈ +1.78/节点、下游 −1.65、垂直链接 CX=0 恒 0），**无单点伪影**；净 6.06 是 ±1.7 大数抵消后 ~0.3% 残差失衡；
   - 对照探针：纯周期 x + 圆柱（无出入口）τ=0.542 跑 12000 步稳定（|u|max≈0.135 有界）→ 核心 BGK+反弹无罪；只出入口（无圆柱）2 万步干净 → 出入口单独无罪；
   - 结论：**Zou/He 入口+对流出口与反弹壁面组合在 τ≲0.55 注入慢变压力波**，动量交换力（~1% 残差）对慢波极敏感。修法待 v1.1：Bouzidi 次网格反弹（bouzidi.py 已写好待接入，注意固体清零与 q<0.5 存储冲突）或 MRT 碰撞；
   - **规避口径**（v1.0 采用）：逐周期块均值（29 块 std 0.05–0.10，块间爬升 +3~5% 与 BL 增厚一致）+ Cl 相干峰幅（Hann 谱主峰 2|X|/Σw，宽带噪声不膨胀）；St 双测法（谱峰 vs 峰频）互差 <2%。

## §4 实验协议（v1.0 基线）

- 几何：840×280 lu（30D×10D），D=28 lu，圆柱中心 (170,140)（上游 ~6D），blockage 0.1，U=0.1（Ma≈0.17）。
- Re=50/100/150/200 → τ=0.668/0.584/0.556/0.542（均 ≥0.54，避开边界泵能区）。
- 记录自适应：T≈D/(U·St_lit(Re))，transient 20T + record 30T（ΔSt/St≈3%）。
- 指标：时均 Cd、Cl RMS、St（升力谱 Hann+抛物线插值）；文献 St≈0.2124−4.592/Re。
- 4 个 Re 并行后台（numba 单核/进程，~26 ms/步）。
