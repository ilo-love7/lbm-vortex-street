# LBM 圆柱绕流与卡门涡街（N5）

从零实现**二维格子 Boltzmann（D2Q9 + BGK）**流体求解器：圆柱绕流卡门涡街，Re=50–200 参数扫描，升阻力系数与 Strouhal 数对照文献经验式。

> 博远线上科研提案 N5 ｜ 流体/CFD ｜ 数值仿真 ｜ v1.0.0 ｜ 2026-11-09

## 方法

- **D2Q9 + BGK**：f_eq = wρ(1+3c·u+4.5(c·u)²−1.5u²)，ν=(τ−0.5)/3，Re=UD/ν；
- **边界**：圆柱半程反弹（link-wise），西 Zou/He 速度入口，东一阶对流出口，顶底自由滑移；
- **测力**：动量交换法 F=2Σ e_i f_i*（静壁），Cd=F_x/(½ρU²D)、Cl=F_y/(½ρU²D)；
- **St**：升力时程 Hann 窗 FFT + 抛物线插值主频，St=f·D/U；
- **实现**：numba JIT 核（与 numpy 路径逐位对照一致，54→9 ms/步），纯 CPU 无数据集。

## 结果摘要（840×280 lu，D=28，U=0.1，τ≥0.542，transient 20T + record 30T）

| Re | Cd_mean* | Cl 幅† | St | St 文献 | 相对误差 |
|---|---|---|---|---|---|
| 50 | 1.80 | 0.035 | 0.138 | 0.121 | +14.6% |
| 100 | 1.64 | 0.394 | 0.178 | 0.166 | +7.0% |
| 150 | 1.71 | 0.599 | 0.196 | 0.182 | +7.8% |
| 200 | 1.75 | 0.868 | 0.207 | 0.189 | +9.5% |

\* Cd = 逐周期块均值（29 块，块间 std 0.05–0.10；瞬时力在 Re≥100 被边界慢波污染，块均值口径稳健，详见报告 §2.2）。
† Cl 相干幅 = 升力谱主峰单边幅值（Hann 窗）。
（文献 St ≈ 0.2124 − 4.592/Re，Fey et al. 1998；文献 Cd≈1.47/1.35/1.35/1.35，Cl 幅≈0/0.33/0.55/0.70）

- St 全部 +7~15%（粗网格阶梯壁面系统偏高，趋势正确、双测法互证）；Cl 幅随 Re 增长曲线正确；
- Cd 块均值偏高 +20~30%（阶梯壁面 + 10% 阻塞 + 边界层欠分辨），块间稳定、趋势可用；
- **已实测标定稳定性红线**：τ≤0.53 时出入口+反弹边界组合泵能发散，本配置 τ≥0.542。

## 未做项（如实标注）

- **瞬时力时程在 Re≥100 被出入口+反弹边界注入的慢波污染**（约半数瞬时 Cd 为负、慢漂 ±2）：非实现 bug（纯周期对照稳定、逐节点抓拍无单点异常），已用逐周期块均值 + Cl 相干幅口径规避；根治需 v1.1 Bouzidi 次网格反弹（`src/lbm/bouzidi.py` 已备未接入）或 MRT 碰撞。
- Cd 绝对值偏高 +20~30%（阶梯壁面/阻塞/欠分辨）；网格收敛性（D=28→56）未做。
- Re=300+、振荡圆柱、串列双圆柱等扩展未做（v1.1 方向）。
