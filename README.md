# LBM 圆柱绕流与卡门涡街（N5）

从零实现**二维格子 Boltzmann（D2Q9 + BGK）**流体求解器：圆柱绕流卡门涡街，Re=50–200 参数扫描，升阻力系数与 Strouhal 数对照文献经验式。

> 博远线上科研提案 N5 ｜ 流体/CFD ｜ 数值仿真 ｜ v1.9.0 ｜ 2026-11-23

## 方法

- **D2Q9 + BGK**：f_eq = wρ(1+3c·u+4.5(c·u)²−1.5u²)，ν=(τ−0.5)/3，Re=UD/ν；
- **边界**：圆柱 **Bouzidi 次网格反弹**（解析壁距 q 插值，二阶几何；q≡0.5 即半程反弹），西 Zou/He 速度入口，东一阶对流出口，顶底自由滑移，**东西海绵层**吸收反射慢波；
- **测力**：动量交换法 F=Σ e_i[f_i*+f_ī_new]（静壁），Cd=F_x/(½ρU²D)、Cl=F_y/(½ρU²D)；
- **St**：升力时程 Hann 窗 FFT + 抛物线插值主频，St=f·D/U；
- **实现**：numba JIT 核（与 numpy 路径逐位对照一致），纯 CPU 无数据集。
